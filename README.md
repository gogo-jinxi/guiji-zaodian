# 硅基早点 · 每日存档

AI 圈的每日早点：从 X 时间线与 OpenAI、Anthropic 官方动态中筛选出的 5–10 条最有价值内容。

- **音频播客**：小宇宙搜索「硅基早点」，每日更新（AI 生成演播）；每日 mp3 同步归档在本仓库 `audio/` 目录
- **本仓库**：每日文字精选（含 X 原文链接）与口播稿
- **生成方式**：Kimi 每日早晨读取 X（For you / Following 时间线 + 官方主页），AI 筛选整理

## 目录结构

```
digests/          每日精选（markdown，含原文链接）
  2026-10-19.md
podcast/          每日口播稿（txt）
  2026-10-19.txt
audio/            每日音频（mp3）
  2026-10-19.mp3
```

## 说明

- 小宇宙平台规范禁止在 shownotes 中放置站外链接，原文链接只保留在本仓库和每日交付的本地副本中。
- 标记「原帖链接未获取」的条目，是读取时未能取得 URL，可在 X 按作者账号搜索到原帖。
