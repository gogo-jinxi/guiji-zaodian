## 深度阅读

【12】Node2Shell 演进为 HTTP2Shell · HN 340 分
昨天 Brotli 未授权 RCE（CVE-2026-111497）的波及面继续扩大：同一攻击思路从 Node 生态蔓延到多个 HTTP 库与应用，blast radius 远超最初评估。
链接：https://www.aikido.dev/blog/python-packages-vulnerable-node2shell-brotli-cve-2026-111497
白话解读：攻击者只要让服务器解压缩一份恶意数据就能接管它。昨天影响 Node.js、Bun、Envoy，今天发现 Python 生态里多个 HTTP 库同样中招。对从业者的意义：检查的不只是框架版本，而是整个依赖链里所有碰过压缩数据的库。
