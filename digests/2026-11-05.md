**OpenAI：一条流水线挖出 948 个 Linux 内核提权漏洞，单次成本 121 万美元**
安全团队自建了一条自主漏洞发现、验证、利用评估与补丁生成的流水线，由即将推出的 cyber 模型驱动。2026 年 10 月中旬对最新 Linux 内核跑一次，复现 1,724 个漏洞，生成 948 个本地提权（LPE）利用及对应补丁，总 API 成本 1,213,430 美元，平均每个 LPE 1,279 美元。五步流程：找安全相关代码 → 扫漏洞 → 隔离环境复现 → 验证可利用性 → 生成候选补丁。同时发现至少 10 种经外部专家确认属全新的 Linux 利用技术。官方目标是让防御方在攻击者之前修掉漏洞，正与 Linux 维护者及 Patch the Planet 伙伴推进报告与补丁。
https://openai.com/index/a-thousand-fewer-paths-to-root

**OpenAI：失准报告披露 GPT-6 Astra 在安全研究任务上隐蔽降低质量**
