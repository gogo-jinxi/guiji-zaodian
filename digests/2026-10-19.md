值得关注：头部 AI 实验室第一次把「公共利益」从口号变成有比例、有触发机制的结构性承诺；治理结构正在变成竞争维度。

## 新品速览

**10. Beam.win —— Product Hunt 今日榜第一（235 票）**
在一台 Mac 上跑 AI agent，在另一台 Mac 上直接查看和操作它的窗口——把「远程桌面」重新想象成「远程 agent 桌面」。
值得关注：agent 常驻一台机器干活、人随处查看干预，可能是多设备时代的标配形态。

**11. buddylist（78 票）与 walkai-talkai（78 票）—— Product Hunt 今日榜**

值得关注：功能未必强，但说明 agent 的交互形态远未定型，什么样的壳都有人愿意试。

## 深度阅读

**1. 黑客用 AI 智能体入侵 John Deere、SharkNinja 等 100 多家网站（The Verge）**
AI 安全公司 Norforge 发现一名黑客用开源 AI 平台 Cairn 编排智能体，入侵了超过 100 个网站，受害者包括 John Deere、SharkNinja、Cummins。

链接：https://www.theverge.com/ai-artificial-intelligence/1013643/ai-agents-hack-john-deere-shark-ninja-cummins

**2. Meta 详解 Prometheus 吉瓦级超集群（Meta 工程博客）**
位于俄亥俄州 New Albany 的吉瓦级超集群一期已建成，正在训练 Muse 系列基础模型，目标扩展到约 100 万张 GPU。文章拆了网络、散热和可靠性工程的细节。
白话解读：「吉瓦级」第一次从新闻标题变成有工程细节可读的运转中系统。关心算力供给和基础设施成本的人值得一看。

**3. DeepSeek-V4.1-Flash 登顶 Code Arena: WebDev 开源榜（Arena）**
DeepSeek-V4.1-Flash-20261017 (Max) 超过 Kimi K3 (Max)，成为 WebDev 编码榜单第一的开源模型，成本低约 10 倍。

链接：https://x.com/arena/status/2111894091168682086

**4. GitHub Security Lab 用开源 agent 找出 24 个安卓漏洞（GitHub 官方）**
其中一个位置信息泄露漏洞存在于一款下载量千万级的导航应用里。GitHub 同时放出了在自有项目上复跑这套 taskflow 的方法。
白话解读：安全审计正在被 agent 化——以前请一次安全团队做的事，现在可以当成 CI 的一部分跑。和第 1 条对照：攻防两边都在 agent 化。
链接：https://x.com/github/status/2111880011485516083

**5. 论文《Hybrid Reasoning Agents》：在潜空间思考、用文字行动（Hacker News，465 分）**
arXiv 新论文：让 agent 的「思考」发生在连续潜空间，而不是逐字生成推理文本，行动时才落到文字。目标是省 token、提速、突破文本推理的带宽瓶颈。
白话解读：现在 agent 又慢又贵，一大原因是「每一步思考都得写成字」。这条路线如果走通，agent 的推理成本结构会变。做 agent 基础设施的值得扫一眼。
链接：https://arxiv.org/abs/2610.18861

**6. Mistral 发布 Timestral：时间序列基础模型（Hacker News，233 分）**
把「基础模型」思路搬到时间序列预测：不再为每条业务曲线单独建模，一个预训练大模型直接做预测。
白话解读：销量预测、流量预测、设备监控这类活，以前要数据科学家一条条调；路线成立的话，这类需求会变成「调 API」。做数据产品的可以关注落地效果。
链接：https://mistral.ai/news/timestral/

**7. 密歇根大学 AI Coding 课程 EECS 498-016（Xudong Han 推荐）**
《Applied Agentic Software Engineering》，15 周：从 Aider + 本地小模型入门，到自己实现 Tool Call、Agent 循环，再到让学生自己造一个 Coding Agent、放它独立干活，最后写清楚它为什么翻车。
白话解读：「会用 agent」正在变成一门可教学的手艺，课程设计本身就是一份自学路线图——它的作业要求（解释 agent 为什么翻车）比大多数培训班实在。
链接：https://x.com/Xudong07452910/status/2111979391546773875
