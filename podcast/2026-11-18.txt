早上好，我是小硅。OpenAI 放出 GPT-6.2 的两款模型。Google 把新模型推上了全球搜索。英伟达交出一份翻倍的季报，另外还有一整夜的网络故障。

OpenAI 昨天下午发布两款模型，GPT-6.2 Astra 和 Sol。Astra 接的是最难的活。公司说它把专业工作和科学研究两类评测都推到了新高。每个任务成本不到原来的三分之一，接口价格再降两成。Sol 是日常那档，接替 GPT-6.1，主打快和省。

这次单独被强调的能力是网安。OpenAI 称 Astra 是公司史上最强的网安模型，在自家一个内部端口测试上比上一代高 22 分。能力涨得这么快，它没有一次性全量放开，改成按批推进。

第三方的成绩单同一天出来。Artificial Analysis 的智能指数里 Astra 排第二，仅次于 Claude Fable 5.2。Perplexity 用自建基准测了两个数字：Astra 得分 0.783，每任务十二块五美元；Sol 得分 0.746，两块六。同样十来个百分点的提升，Astra 的价钱是 Sol 的五倍。

国内实测的口径不一样。数字生命卡兹克用一个真实项目跑完之后说，它极致省钱，但偏科严重，沟通可读性依旧拉胯。

能用的地方在铺开。ChatGPT 的 Work 和 Codex 都上了，Plus、Pro、企业版和教育版全覆盖，最高档 Pro 500 还能开 Ultrafast。Perplexity 的搜索和 Computer、Conductor、OpenClaw 也都接了进去。OpenClaw 同时结束了 ChatGPT 登录的测试，商业套餐能带进第三方工具用。

OpenAI 自己的公告开头有句话很直白：这两款模型是为真正的活儿做的，不是为跑分做的。同一天它还发了销售版和医疗版，销售版接进 Salesforce、Hubspot、ZoomInfo，三十多个插件；医疗版二十多个插件，合作方里有 CVS Health 和 Cigna。

Google 那边也在动搜索。它宣布 Gemini 4 Hydrogen 已经在全球范围的 Google Search 上线，官方口径是搜索有史以来最大的一次模型升级。

改动落在四处。它更准确地判断你问的是什么。查的时候它会自己决定分几个方向、查完怎么摆链接。回复的排版更可视化，也更适应屏幕。多语言能力也更强了。对普通用户来说，最直接的感受是结果页会变样子。以前是一列链接，现在答案会被组织成能看懂的结构。

Google 的产品负责人顺手演示了一个用法。把一堆资料丢给 Gemini Notebook，它能把资料转成可以点的网站。他做了一张元素周期表的，点每个元素能看说明。

Google AI Studio 也更新了三项。可以在里面买自定义域名，可以直接构建安卓 App 并上架 Google Play，还能在 Studio 里给这个 App 接上模型。安卓 App 那项目前只对美国开放。

这套东西还能干别的。Google 的开发者账号演示了一个专利归档项目。它让新模型去读一百年前的专利申请，靠空间推理把条目在三维里摆出来。

英伟达把季报交了。截至 10 月的三个月，营收 1160 亿美元，同比翻倍，比华尔街预期的 1090 亿还高。数据中心收入 1076 亿，占了九成三；季度利润 653 亿，同样翻倍。

财报里有一处细节被 FT 单独拎了出来：英伟达不再披露新加坡的销售额。新加坡这块以前是投资者观察它对华出货的窗口，现在窗口关了。

Anthropic 的 IPO 本周定价。CNBC 从多个信源拿到消息，说价格很可能落在 70 到 78 美元区间的上沿或更高。彭博的节目里有人算，上市当天它的市值可能摸到 1.4 万亿美元。

质疑也同时来了。Michael Burry 说 Anthropic 是在押上自己的全部存在，去赌一个乐观预期，他本人不打算持有。另一位投资人在电视上直接说，这是史上最被炒作的一次 IPO。

股权结构里有个数字要单独说。TechCrunch 披露，上市之后 Amazon 会持 14.7%，可转债全转之后是 23.8%；Google 持 13.7%。两家加起来接近三成，而且都是没有投票权的股份。

同一周微软交了另一份答案。Ignite 大会上它的模型部门发了七款模型，主打性价比。编码那款达到 GPT-6.1 Sol 九成八的性能，价格只要四成。对上 Claude Opus 5.5 能到九成六的性能，价格只有百分之五。它还推出一个叫 Licensed Weights 的方案，企业可以定制，放在自己的云里跑，权重和数据都自己握着。

政策这边还有一条。商务部正在推进远程算力的管制，也就是限制别人隔着网络用美国的算力。英伟达在规则成型前游说过反对，没有成功。

安全这条线上今天格外吵。NSA 的内部机密网络宕机，路透、BBC、华尔街日报、Forbes、NBC 都报了，官方说原因是一处技术故障，没有发现攻击迹象。苹果的服务也大面积挂了一阵。

Java 那边出了一个能远程打的漏洞，叫 Java4Shell，编号 CVE-2026-114938，问题出在 OpenJDK 处理 Base64 的时候。Hacker News 上两个帖加起来四百来分，说明有多少人靠 Java 吃饭。

Waymo 把无人车从全美的高速上撤了下来。起因是加州上周不许它上高速，它干脆先全部撤了。

FEMA 出来给这几天的连环故障降了温。它的说法是很多所谓中断其实是计划内的例行测试，每三年至少做一次。

Claude Code 上线了一个实验特性的开关，叫 Code Mode。以前模型查一次工具就得停下来等你回话。现在它先把要做的几件事写成一段脚本，一口气跑完。长命令还在跑的时候，它就能先回你。默认关闭，要开得设一个环境变量。

GitHub 交了个反常识的成绩：自家的 Copilot Fusion Max 在 Terminal-Bench 4.1 上解出 71.2%，比两个最强的前沿模型高 5.4 个点，成本却低 88%。

SGLang 在上周的峰会上说，他们合并进去的 PR 里大约 95% 是 agent 写的。前端那批人早就在数 PR 数量，现在轮到后端了。

Claude 平台上了联合计费，还在测试。Factory、Linear、Ramp 这些工具的用户，可以直接用自己公司的 Claude 账户付接口费用，平台不用自己搭计量和开票。现在接进来的一共十五家左右。

Claude 桌面端也放开了构建通道。Windows 和 Mac 都能在设置里切到最新版频道，拿到更频繁的修复。

一个明确关掉了提现权限的接口密钥，还是被人搬走了 1039 万美元的 USDC。复盘说智能合约没被黑，官方 SDK 也没有漏洞，问题出在别的地方。

X 上 Grok 的机器人替人打了 90 分钟电话，把 AT&T 一个复杂问题办完了，卡在 90 分钟的通话上限。

Instagram 开始测试识别盗用脚本的功能，起因是一批脱口秀演员投诉 AI 账号在搬运他们的段子。

Coinbase 把交易插件接进了 ChatGPT，能连账户、管组合，每笔下单还要人工确认。

Treg 出了一个求职接口，agent 可以搜空缺、给简历打分、找到招人的经理。打分用的是一个决策模型，一次不到千分之一美元。

MiniMind 这个项目教人用 3 块钱成本、2 小时训练一个 6400 万参数的小模型，从零用 PyTorch 写全套链路。

Jane Street 开源了一个叫苏格拉底导师的技能包，装上之后模型不灌知识，只提问，逼你自己想。

苹果在 Mac 上推了自家的容器方案，把 Docker Desktop 的痛点直接顶到了 GitHub 5.15 万星。

微软的网络安全模型顺手讲了个做法。它先扫六个常用开源项目。安全研究员在维护者看到之前逐份核查。最后维护者收到 99 份核查过的私密报告，躲开被 AI 生成的假报告淹没。

几个从今天素材里浮出来的判断。Vercel 的 CEO 说，以前做产品的流程是用户是人，跑用户访谈，画用户旅程。现在用户是 agent，跑的是评测，评测反过来决定工程怎么做。

Box 的 CEO 说，每个员工的 token 支出曲线还没看到天花板，越靠近 AI 的人越觉得现在只是开头。

一位投资人把 2026 年的基础设施战争拆成了四段。一季度拼氛围编程，二季度拼编排框架。三季度拼沙箱，四季度拼 agent 化的持续集成。

有人替所有开发者喊了一句，请把权限弹窗减少一点，让 agent 在 Mac 上能自己干活。苹果的回应是新加了一批更吓人的弹窗。

Altman 昨天批评了行业的宣传方式。他的说法是这样的。如果人们拿到了治愈癌症的技术，也拿到了便宜的商品，代价却是交出自主权和对未来的掌控。那种宣传就是坏的。他说自己不想生活在那样一个世界里。

网络安全的生意被反复提。有人在电视上说这是 2027 年最好的生意，理由是六天里出了五起大中断。Greg Isenberg 也这么说，他给的三个词是经常性收入、关键任务、每个月都更急。

Demis Hassabis 离开 Google DeepMind 之后自己开的公司，融了 50 亿美元。

OpenAI 还宣布和北约合作，帮盟国加固网络防御。这条放在它的官方新闻列表里，跟这两天的起诉形成呼应。

有个细节是别人测出来的。Nick 拿五个模型玩维基百科游戏，从同样的 50 个起始页出发，要求走到 Japan。他说 Sol 在这类电脑操作上快得离谱。

Garry Tan 说，他的记忆引擎 GBrain 接下来要用 Rust 重写后端，替掉现在 postgres 加向量检索那套。

Dan Shipper 提了个想法：AI 时代给内容排序，可以按 agent 读它花了多少 token 来算，等于用工作量证明取代点击量。

麦肯锡的测算是，超过七成美国工人会有一部分任务时间被重新分配。其中约四分之一的人，受影响的部分超过一半。

今天最直白的一条是，钱和算力还在往上走，产品和故障在同一天里一起冒出来。小硅先说到这儿，明天早上见。
