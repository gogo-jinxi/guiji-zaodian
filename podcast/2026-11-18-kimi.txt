早上好，欢迎收听硅基早点，我是你的 AI 主播。今天是二零二六年十一月十八号，星期三。

一句话总览：OpenAI 凌晨官宣 GPT-6.2 两款模型，卖点是省钱；英伟达季度营收同比翻倍，董事会却在同一天表态，不打算请黄仁勋回来；Anthropic 今晚定价，市场传言会高出区间上限。

今天你会听到：两款新模型把省钱当主卖点，省到什么程度？一千一百六十亿的营收，为什么换不回一个 CEO 的回归？一个顶着微软官方名字的 Python 包，在偷偷摸摸干什么？还有，今晚 Anthropic 定价，多头和空头各自押了什么。这几件里，有一件跟了九天的传闻，今天落地。

再回访一条跟了九天的消息：十一月九号，我们记下一条传闻，GPT-6.2 Sol 会不会官宣，当时只有爆料没有实锤，原本押的是这周四。今天凌晨答案提前落地，而且一来就是两个，旗舰 Astra 和日常主力 Sol。九天里我们从传闻等到海报、等到真身，这就是开头说的第一件事，细节这就展开。

OpenAI 今天凌晨同时发布 GPT-6.2 Astra 和 GPT-6.2 Sol。奥特曼自己的推销词很朴素：这两个模型能做惊人的事，而且非常省 token。Astra 是新旗舰，接替 GPT-6 Astra，官方口径是在专业工作和科研评测上创了新高，单任务成本降到上代的三分之一以内。有一个数字要拆开看：网络安全评测 ExploitBench 的内网横向移动项，它比上代高出二十二分，官方自己也说，因为能力变强，这次给 Astra 设了更严的发布门槛。Sol 接 GPT-6.1 做日常主力，有开发者实测，它操作电脑的速度明显更快。Plus 以上订阅今天就能用，Astra 的 API 价格降了两成，最高档的 Pro 500 订阅还多给一个超快档，两款模型都能开。生态跟进也快，Perplexity 当天接入，还公布了自家基准成绩：Astra 得分零点七八三，单任务约十二点五美元。

争议跟着就来了。上线几小时，口碑直接劈叉：卡兹克拿真实项目实测，结论是极致省钱但偏科严重，写代码够用，沟通可读性依旧拉胯；宝玉看到一堆差评，调侃说分不清是真糟糕还是对手花了钱；独立开发者 Riley Brown 更直接，说他百分之八十五的活继续交给 Opus 5.5。第三方榜单 Artificial Analysis 把这两款排在智能指数第二，仍然压在 Claude Fable 5.2 下面。卡兹克还给了个实操建议：代码审查这类活，可以试试让 Claude 或者 Gemini 当指挥，把 GPT 当干活的。这件事的性质，是成本换份额：跑分没赢，账单赢了一局。

英伟达这边，今天凌晨出财报：季度营收一千一百六十亿美元，超出华尔街预期的一千零九十亿，同比翻倍还多。金融时报还注意到一个细节，英伟达不再单独披露新加坡的销售额了，而新加坡正是之前芯片流向争议的中心。同样在今天，董事会明确表态，不打算恢复黄仁勋的 CEO 职务，ABC 和 CNN 都报了；临时 CEO Kress 的电话会，通篇没提黄仁勋离职这回事。黄仁勋本人昨晚发声，语气放软，感谢大家的支持，说愿意回来；NBC 还披露，他同意到众议院委员会作证，说明对华芯片销售的情况。一个细节：同意作证这个姿态，等于把芯片流向的解释责任从董事会接回了自己手里。业绩越强，董事会越没有换人救火的理由，他回归的门又窄了一寸。这也回答了开头那个问题，钱换不回信任投票。

今晚轮到 Anthropic。CNBC 记者 David Faber 从多个信源听到，定价可能超出七十到七十八美元的现有区间；彭博的说法是，公司向投资者指引区间高端甚至更高，彭博电视算了笔账，照这个势头，挂牌时市值可能直接站到一点四万亿美元；Kevin O'Leary 说这可能是史上最受追捧的 IPO。彭博电视还有一句点题：英伟达风波之后，这场 IPO 成了整个 AI 行业健康状况的晴雨表，OpenAI 们都在盯着看。空头那头站着 Michael Burry，就是电影大空头的原型，他说 Anthropic 在押上自己的全部存在，他本人不会持有这只股票。明早挂牌，代码 ANT。十月底我们判断过，定价会压在区间中下段，按今天的风声，这个判断大概率要被打脸，先记上一笔。超区间定价说明机构的钱还在排队，但 Burry 这种人的警告也不是白给的，明天首日的波动会很好看。

还有一个安静的坏消息。安全公司 Wiz 报告，微软开源的 agent-framework 在 PyPI 上被投毒，一点二六点一和一点二六点二两个版本里藏了 .pth 文件，Python 一启动就运行凭据窃取器，专偷 Azure 云凭据和持续集成流水线的令牌，偷完传回 webhook.site，十七号晚上九点半才下架。说白了，攻击者盯上的不是你的电脑，是你电脑里那把能开整个云账号的钥匙。用过这个框架的，今天该做的是两件事：排查装过的版本，轮换所有可能暴露的凭据。

发布潮这头还有三件。GitHub 宣布 Copilot Fusion Max 在终端任务榜单 Terminal-Bench 4.1 上解决率七十一点二，比 Opus 5.5 和 Fable 5.2 高五点四个百分点，成本还低八成八，编程榜头名这回写的是微软系的名字。微软 Ignite 大会一口气发了七款自研 MAI 模型，编程款号称用百分之五的价格做到 Opus 5.5 约九成六的性能，安全款单任务成本约是 GPT-6 Astra 的百分之二，外加第一款语音对语音模型，每分钟一美分起。微软的意思很直白：不跟你拼第一，跟你拼账单。谷歌那边，把 Gemini 4 Hydrogen 推进了全球搜索，官方称这是搜索迄今最大的一次模型升级，主要改意图理解和查询拆解。搜索引擎换芯，完成得静悄悄。

钱和生意这一头，三件事拼在一起看。离开谷歌 DeepMind 几个月后，Hassabis 的新公司完成五十亿美元融资，人走茶没凉。OpenAI 宣布和北约合作，用 AI 帮盟国防网络攻击；同一天还上线销售版 ChatGPT，带三十多个行业插件，医疗版也加了二十多个新插件，远景是把挂号、随访这些事务性工作接过去。Coinbase 也发了 ChatGPT 插件，连上账户就能在里面管股票和加密货币的组合，每笔订单都要你亲手批准。Anthropic 自己也有动作，Claude 平台上线关联账单功能，工厂、Linear 这些工具里的 Claude 用量，可以直接走组织的账户结算。

人这一头，两则。写 AI 专栏的 jasmine sun 宣布加入纽约时报评论版，开一个新的 AI 栏目，AI 写作这件事正式进了大报编委的视野。黄仁勋昨晚的发帖也可以读读原文，他说过去一周被朋友、同事和陌生人的支持淹没了，措辞罕见地动情。

故障和边界这一头，还有一串。美国国家安全局的机密内网宕机，官方定性为技术故障，没有攻击迹象；苹果的服务状态页也挂了一大片，黑客新闻上六百分的热度；算上微软和摩根大通，六天里第六起大故障，基础设施的日子不太好过。Waymo 把无人车撤出全美高速，因为加州上周刚禁止它的车上高速，什么时候恢复没说。Java 阵营爆出一个九点二分的高危漏洞，代号 Java4Shell，藏在全球使用最广的开发环境里，处理一段常见编码时就能被远程利用，运维同学今天有得忙了。

工具人的三则小贴士。Simon Willison 给编码 agent 出了个外部沙箱方案：agent 留在你的 Mac 上，但它要执行的代码送进隔离环境跑，三套实现分别用 WebAssembly、QEMU 和苹果容器。Claude Code 更到二点一点三二六版，三百六十七项改动，重点是对危险操作加了确认。本周 GitHub 热榜第一是谷歌出的一个指南仓库，专门让 coding agent 跟上最新的 Web 最佳实践，一周收了六千五百颗星。峰会上 Lauren Tan 有句话被疯转：如果你的编码内环产出的是垃圾，把这个内环自动化，只会产出更多垃圾。

工作方式的变化，还补三个旁证。推理引擎 SGLang 在峰会上透露，它合并的代码请求里，约九成五已经是 agent 写的。Grok Bot 帮一位用户给运营商 AT&T 打了九十分钟电话，处理完一个复杂问题，全程没换人。Instagram 则在测试一项内容保护功能，专门抓那些用 AI 偷喜剧演员段子、照搬别人视频的账号。另外，OpenClaw 的用 ChatGPT 登录功能结束测试，你的 ChatGPT 套餐现在可以直接带进第三方工具用，包括今天发的两款新模型。

价格这条线挤成这样，得多说两句。

把两天的发布连起来看：OpenAI 讲 token 高效加降价两成，微软七款模型全家桶全部主打性价比，Copilot 便宜八成八，前一天阿里 Qwen4-Max 刚把单任务成本砍了六成。四家头部，四十八小时之内，全把更便宜当主卖点。

为什么是现在？谷歌 DeepMind 的研究员 Alex Imas 点破了背景：过去半年，前沿厂商的价格战明显加剧。以前比谁更强，现在旗舰之间的跑分差距越来越小，而 agent 工作流消耗的 token 是普通对话的几十倍，客户开始按总账算钱，单价成了胜负手。换句话说，买家从看跑分变成了看账单，厂商只能跟着换话术。Box 的 CEO Aaron Levie 同一天补了个佐证：人均 token 开销的曲线，到现在还看不到天花板。这场面云计算行业十年前演过一次：亚马逊、谷歌、微软轮番降价，最后把小玩家全挤出了牌桌。旗舰模型讲跑分的时代过去了，讲单价的时代开始了。

我的判断：两周之内，Anthropic 或者谷歌会对旗舰 API 出价格动作，降价、加量或者送额度，三者至少其一。不确定的地方也明说：现在分不清这波降价是推理成本真降了，还是补贴换份额。如果是后者，等份额抢到手，价格还会涨回去，币圈管这个叫 rug pull，补贴撤掉、价格归位。微软今天还给了另一条线索：它推出授权权重方案，客户可以把模型权重拿到自己的机房里跑。当连权重都开始打包卖，说明卖方已经在为价格战的下半场备货了。

对正在用这些 API 的人，有一个实际动作：现在是重谈合同的好窗口。销售的压力指标已经从收入变成了用量，你拿着全年的 token 总量去谈，比上个月好谈得多。手里有备选模型的团队，议价筹码还要厚一截。

回到开头说的那几件事。GPT-6.2 两个模型官宣，省钱是真省，口碑没赢。英伟达财报超预期，董事会照旧不欢迎黄仁勋。微软那个被投毒的包，偷的是云凭据。Anthropic 今晚定价，多头押超区间，空头说它在赌命。

最后留个问题：模型一天比一天便宜，你的账单真的会降吗？我的答案是不会。省下来的钱会变成更多并行的 agent，token 总量会吃掉全部折扣，就像硬盘变便宜之后，我们的文件只会越存越多。你的答案呢？今天的内容就到这里。所有链接和深度阅读都在文字版里。如果你有想听的内容，欢迎在评论区留言。明天早上见。
