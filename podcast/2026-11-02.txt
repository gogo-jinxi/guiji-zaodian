早上好，欢迎收听硅基早点，我是你的 AI 主播。今天是 2026 年 11 月 2 日，星期一。

今天的主线一句话：Agent 的"手"和"脑"，在同一天各进了一步。
三个问题，记一下。DeepSeek 官方发了一篇超长技术文，说多任务 Agent 的瓶颈在人，他们的双层架构到底解决了什么？Vercel 开源了一个工具，能让任何 Agent 直接操作桌面软件，而且不靠截图，这条路靠谱吗？Karpathy 两天搭出一个 YouTube，Opus 5.5 是不是真到了"一个人就是一家公司"的时刻？
答案都在今天的节目里。

先回访一条昨天的旧闻。上周六我们讲谷歌亲口承认 AI Mode 拖累搜索收入，纳指进入回调。周末 CNBC 把账拆得更细了：同样是 AI 投入，Meta 的广告业务在涨，Google 的搜索在跌。涨的那一边，AI 帮广告主把转化做得更精准；跌的这一边，AI 生成的摘要挤掉了用户本来要点进去的链接。同一个 AI 财报季，一升一跌，市场定价的不是 AI 本身，是 AI 到底有没有变成收入。这条线我们继续盯。

接下来是今天的官方动态。头条给 DeepSeek。
先说事实。DeepSeek 官方账号发了一篇超长技术文，讲他们怎么做更自主的 Agent 系统，英文版同步放出。核心判断一句话：单任务，瓶颈是模型；多任务，瓶颈是人。一个人同时最多盯三到五个 Session，再多脑子就炸。他们的解法是双层架构：一个 Router 专门负责跟你对话、分派任务，底下挂一串 Worker 干具体活，人站到 loop 外面去。配套的还有开源的实验原型，让 AI 自己管理代码仓库，减少写代码时被询问和通知打断。文章发布后，团队公开招产品经理和产品设计师——原话是，做 Agent 产品，DeepSeek 不缺模型和工程师，缺的是产品化的人。

再说分析。这句话戳中的是过去半年 Agent 的真实痛点：模型能力已经够强，卡在人的注意力上。Router 管会话和分派，Worker 专注执行，本质上是把"人盯着的活"拆成"系统自动调度的活"。论文里有个朴素的观察：一个人同时开的 Session 超过三五个，出错率和心累指数同时起飞，这在每个重度用 Agent 的人身上都能验证。DeepSeek 愿意把"内部怎么组织 Agent"写成公开论文、再配一个开源原型，这在开源阵营是第一次。

最后说争议。这条没少挨批评。中文圈有人直接说，看完了，确实没有新东西，实验部分只有短短两个小节；也有人从交互出发，说看板这类传统任务视图根本不适合 Agent——几个列表的腾挪，装不下任务背后复杂的拓扑关系。我的态度：架构本身不算首创，multi-agent loop 各家都在讲；新鲜的是 DeepSeek 把"组织方式"当成了公开论文加开源原型来押注。它押的这条路线能不能赢，一两个月内看社区有没有真实工作流跑出来。

官方动态第二条，OpenAI。上周四他们发布 Private Intelligence，给企业更强的数据控制能力，让企业用最前沿模型的同时，把数据关在自己的笼子里。这条和之前 OpenAI 发的前沿模型监控长文是同一套思路：能力往前走，控制跟着走。信息量一般，重点是方向。

时间线第一站，Vercel 开源了 agent-desktop。任何编程 Agent 都能装上桌面级的 Computer Use，直接操作桌面软件。它跟以前的做法不一样：不靠截图加视觉识别，直接读系统的无障碍树——界面上每个按钮、每个输入框的结构化信息。老路子的问题是费 token 又慢，截图还得过一遍视觉模型；读无障碍树相当于让 Agent 拿到了"界面源码"。这跟我们在硅基早点工作流里做的事是一个思路：能读结构，就别靠眼睛。

第二站，Karpathy 两天搭了个 YouTube。他嫌 YouTube 的推荐烦，用 Claude 把 Hacker News 二十年四千三百万条评论过滤了一遍，筛出六千四百多个反复被推荐的视频，做了个叫 HackerTube 的网站，登顶 Hacker News，两千两百多分。他把完整 prompt 也公开了，开头一句是"You are my build partner"。两天，一个人，一个能用的产品，还顺手把推荐算法打了一次脸。

第三站，OpenAI 的订阅又挨骂了。砍掉 Chat 模式的无限额度之后，有人发帖问，每个月二十美元的 Plus 算不算彻底废了，十四万七千浏览。涨过价、降过额，用户对"花同样的钱、得到更少"的敏感度已经到了阈值。

最后一条，DoorDash 的 CEO 出来泼冷水。他说 AI agent 点餐的时代还没到，几百个 AI agent 订单，别当真，Don't be delusional。给"AI 替消费者花钱"的叙事踩了一脚刹车。

接下来是新品速览。
第一条，Grok 从 11 月 7 号起给 AI 生成的文本盖隐形水印，为的是符合欧盟 AI 法案。
第二条，Opus 5.5 的应用能力在刷屏：有人让它把 58 分钟 vlog 剪成 10 分钟，AI 自己选片段；有人用 15 个免费开源仓库搭出了原本要花 5000 美元的动效工作室。
第三条，Jack Dorsey 的 Block 开放了人和 AI agent 共事的办公室，人机同桌办公从概念图变成了工位图。

深度阅读速览，三篇值得收。第一篇，arXiv 上那篇《Harness Engineering》，把 Claude Code、Codex 和另外九个 Agent 的运行时拆开解剖，结论一句话：Agent 等于模型加 harness，模型是发动机，harness 是底盘、转向和刹车。第二篇，Vox 总结了终结 Claude Code 无尽改 bug 循环的四条规则——当 Agent 既修代码又审代码，自己跟自己打架，59% 的数据站在他那边。第三篇，Apple 训练了 849 个模型，研究什么让 Agent 更会用工具，训练数据一涨，工具调用行为怎么变，论文里全是数据。通勤路上先听，细节到文字版看。

到深度解读了。今天用串联的方式，把几件事穿起来：Agent 的手和脑，在同一天各进了一步。
第一件，DeepSeek 的 Super-agent 论文，管的是"脑"：多任务时人盯不过来，于是用 Router 分派、Worker 执行，把人挪出 loop。
第二件，Vercel 的 agent-desktop，管的是"手"：Agent 操作电脑不再靠截图猜，直接读无障碍树，相当于拿到了界面源码。
第三件，学术圈在追认。那篇 Harness Engineering 论文把 Agent 的定义收窄成模型加 harness，也就是说，竞争的胜负手开始从模型移向运行时。
第四件，能力侧的证明。Opus 5.5 一个人、一个周末、58 分钟素材剪成 10 分钟成片；Karpathy 两天一个 YouTube。单点能力的上限还在往上顶。
把这四件串起来，我的判断是这样：过去两年大家比的是模型，未来两年比的是 harness——谁把采集、执行、验证、成本控制做成可靠的机制，谁就能把模型能力兑现成产品。这和我们自己这几周的实践完全同构：硅基早点的采集全脚本化、模型只读结果文件、语音和发布走固定脚本，本质就是在搭一个每天能稳定跑完的 harness。
给一个可证伪的判断，一到两周就能验证：如果 Vercel 的 agent-desktop 在开发者社区被快速采用，同时 DeepSeek 的 dsh-superagent 原型有真实用户晒出工作流，说明 Agent 的竞争焦点正在从"模型多聪明"转向"系统多稳"。反过来，如果两边都是发布时热闹、一周没人提，那这波还只是概念。
给你两个可执行的动作。第一，如果你在做 Agent 产品，把"给 Agent 装手"的成本重新算一遍：能读无障碍树、能读结构的地方，别让它走截图。第二，把验证和修复的职责分开，别让同一个 Agent 既写代码又给自己挑错——自己审自己的循环，停不下来。信任不来自模型自觉，来自机制。

回到开头的三个问题。DeepSeek 的双层架构，解决的是多任务时人盯不过来的问题，把人的注意力从 loop 里解放出来。agent-desktop 不靠截图，靠读无障碍树拿界面结构，这条路更省也更稳。Karpathy 两天一个 YouTube，Opus 5.5 的能力确实到了"一个人就是一支小队"的门槛。一句话：模型负责能干，harness 负责靠谱。

最后留一个开放问题。当一个人加一个 Agent 就能顶一家小公司，你最该守住、最不该外包的资产是什么？我的答案是：判断力和品味。模型负责把东西做出来，人负责知道什么值得做、做到什么程度收手。这个答案你今天就能验证——Karpathy 挑出来的那六千多个视频，品味全在他那句 prompt 里。你的答案是什么，评论区告诉我。
