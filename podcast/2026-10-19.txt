早上好，今天是 10 月 19 日。今天的内容有一条真正的大新闻：Anthropic 宣布把最多约百分之二十的公司股份，永久性地投入公共利益。另外我们还会聊到两个用 AI 快速赚到钱的开发者样本，和几个让人眼前一亮的新产品。

先说官方动态。

Anthropic 今天凌晨宣布，成立一个叫 Anthropic 公共利益基金的全资实体，这个实体只做一件事，就是服务公共利益。基金起步会拿到公司百分之五的股份，之后公司估值每比基准线涨百分之五十，董事会就可以再追加最多百分之二，累计算下来，大约百分之二十的 Anthropic 股份会被锁定在公共利益用途上。这还不算完，两位联合创始人之前已经承诺捐出自己百分之八十的个人股权，公司里大约一半员工也参与了股权捐赠配对。

为什么这件事此刻发生？背景是 AI 公司的估值正在以史无前例的速度膨胀， Anthropic 自己就是公共 benefit 公司架构，外界一直质疑这种架构到底有多少约束力。这次的基金相当于把口号变成了有比例、有触发机制、有董事会程序的结构性安排。对从业者来说，它的意义在于，头部实验室之间的竞争，已经从模型能力卷到了治理结构。以后谈一家 AI 公司可不可信，可能要看它的股份里有多少是锁给公众的。

接着说 OpenAI。ChatGPT 里的 Astra Pro 升级了，响应更快，插件和工具调用更稳，最重要的变化是，现在多个智能体可以并行处理一个任务的不同部分，你能实时看到每个智能体干到哪一步了。以前是演示视频里的多智能体编排，现在变成了普通用户界面里的默认体验。这个方向值得留意，agent 编排正在从开发者玩具下沉成大众功能。

还有一条和安全有关。编程工具 OpenCode 两天前披露了一起针对 AI 账号的攻击事件。如果你在用 Claude Code 或者 Codex，建议今天就检查一下你机器上的各家 API key 都放在什么地方。OpenAI Codex 团队一位叫 Tibo 的工程师透露，他们团队和 OpenCode 协作善后，受影响的用户里同时是 OpenAI API 客户的，已经恢复使用，攻击中被扣掉的额度会退还。这件事提醒我们，AI 编程工具普及之后，你电脑上散落的那一堆 API key 本身就是资产，也就是攻击目标。

官方动态之外，今天有两个独立开发者的故事，特别适合路上听。

第一个来自 Indie Hackers。一个叫 Rasty 的开发者，出生在斯洛伐克的小村庄，后来在波士顿做安全，被收购后进了谷歌做 Gmail 工程师，之后自己创办了版权技术公司 Pex，去年把公司卖掉了。休整期间他开始玩 AI 编程 agent，想看看一个 solo 开发者能把这些工具推多远。实验成果是一个叫 Vaultaire 的 iPhone 应用，隐私优先的相册加密工具，所有数据在设备端加密，没有账号体系，不同的解锁图案可以打开完全不同的保险柜。这是他人生第一个 iPhone 应用，三周做完，今年三月上线。第一个月只挣了六十六美元。但是七月流水到了两万六千美元，八月四万一千美元，五个月下载量破了四万，下载到付费的转化率是百分之七点五三。他自己都说，到那个时候，这个玩票的实验开始看起来像一门真正的生意了。这个样本的启发是，这不是素人神话，而是一个有积累的工程师，把 AI agent 当杠杆用。经验负责判断做什么，agent 负责执行怎么做。

第二个故事更近，就发生在中文圈。开发者绪轩国庆假期在外面玩，看着群里一个个晒单，回来赶紧上了一个新站。十月九号下午买的域名，第二天凌晨两点三十八分出了第一单，七十二小时流水五千四百八十美元，第一周到了六千七百多刀。没投流，没买外链，核心就是抓住了一个新冒出来的关键词需求，然后把从买域名到出单的完整过程写成了复盘长文。这个案例最有意思的是速度，从买域名到出单，是按小时算的。在 AI 时代，冷启动的瓶颈已经不是开发能力，而是你嗅觉灵不灵。

再看几个好玩的新产品，都来自今天的 Product Hunt 榜单。

今天的第一名叫 Beam.win，它让你在一台 Mac 上跑 AI agent，然后在另一台 Mac 上直接查看和操作那台机器的窗口。相当于把远程桌面这个概念，重新想象成了远程 agent 桌面。agent 常驻在一台机器上干活，你人在哪都能看能管，这个形态在多设备时代可能会变成标配。

还有两个特别可爱的。一个叫 buddylist，让你像二零零五年用即时通讯软件那样，跟你的编程 agent 聊天，满满的怀旧感。另一个干脆把编程 agent 做成了对讲机，按住说话那种。这些产品的功能未必多强，但它们说明一件事，agent 的交互形态远远没有定型，什么样的壳都有人愿意尝试。

人文向的内容，今天有一条很有画面感。宝玉转发了自己讲 Claude Code 团队怎么审代码的科普视频，那期视频说 Claude Code 团队大约九成代码是 Claude 自己写的，六月到九月合并的修改量翻了一倍多，需要回滚的比例反而降了四成多。视频里演示了两个 AI，一个审代码一个改代码，来回跑了五十多轮。然后最魔幻的来了，这条视频的评论区里，两个 AI 账号互相对聊起来了，而且停不下来。AI 和 AI 聊起来了，这件事已经不再是个比喻，是正在发生的日常。

顺便分享一个数据点。有位开发者在 Indie Hackers 上说，他人工看了一千一百七十个 AI 产品的定价，发现百分之六十三卖的是积分，不是订阅。AI 产品的成本随用量波动，所以大家都在逃离包月随便用。如果你在做 AI 产品的定价，这是一个重要的参照系。

最后，今日观察。我想深入聊的还是 Anthropic 这个公共利益基金。

我的看法是，这件事的真正价值不在慈善数额，而在它创造了一个可核查的锚点。AI 公司谈责任谈了很多年，大多是报告、原则、承诺书，这些东西的共同问题是没法验证，也没法追责。而股份是硬的，百分之五起步、涨百分之五十追加百分之二，这些数字白纸黑字，未来每一次估值跳涨，外界都可以拿着这个公式去问，追加了吗。当然也要冷静，董事会酌情这个表述留了很大的裁量空间，最终成色要看执行。但至少，Anthropic 把治理竞争拉到了一个新维度。当模型能力的差距越来越难拉开的时候，可信的制度设计本身，可能正在变成头部实验室的核心竞争力。这对整个行业是好事，因为它抬高的是所有玩家的承诺成本。

今天的精华就是 Anthropic 把最多两成股份锁给了公共利益，以及独立开发者用 AI 三周做到月入四万美元。所有链接都在文字版里，明天见。
