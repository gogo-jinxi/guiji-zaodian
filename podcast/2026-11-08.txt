早上好，我是小硅。十一月八号，星期天。

今天最值得说的一件事，是昨天还在讨论 Anthropic 的估值能不能撑住，今天 OpenAI 自己先认了这个价。路透援引消息人士说，OpenAI 拿到一百一十亿美元融资，估值一万两千五百亿。这笔钱周五到账，是整轮融资的第一笔，整轮最多可能到两百亿美元。而他们原本的计划，是以一万四千亿的估值融三百亿。

三百亿缩到最多两百亿，一万四千亿缩到一万两千五百亿。这个缩水不是市场传的，是自己签字认的。

今天要听的几件事。OpenAI 融资缩水。金融时报同一天发了两篇，一篇叫《华尔街对 AI 的全押是怎么爆的》，一篇叫《为什么美国恨 AI》。CoreWeave 主动给得州候任州长发信求合作。朝鲜黑客二十分钟从币安盗走六十三亿美元。还有一条，Airbnb 用专用小模型做到了前沿模型百分之一的成本。

先说 OpenAI 这条。把它和昨天那条放在一起看，就能看出这一轮回调走到哪一步了。

昨天是外部对公司的估值分歧：路透说投资人怀疑 Anthropic 能不能按一万五千亿挂牌，华尔街日报采访到的投资者说一万亿更现实。今天是公司自己下调预期：一万四千亿变成一万两千五百亿，三百亿变成最多两百亿。

这两件事的性质不一样。外面的人说贵，公司可以不理；自己把价签改了，说明内部的判断也变了。而且改的时点很具体，就在 AI 板块被抛售之后。

这里我的判断是，这一轮不是某一家公司的问题，是整个行业的定价方式在换。前两年大家给 AI 公司定价，用的是「未来能长多大」；现在开始用「现在赚多少、要花多少」。这个转换一旦开始，所有靠融资活着的公司都要重新算一遍自己的账。

再看金融时报那两篇。同一天，一篇讲钱，一篇讲情绪。这个组合本身就是信息：说明这一轮的问题从财务问题蔓延到了政治问题。

讲钱那篇的标题是《华尔街对 AI 的全押是怎么爆的》。所谓全押，是把资金、把风险敞口、把对未来收益的预期，都压在这一件事上。爆了的意思是，这个仓位现在开始反噬。

讲情绪那篇问的是，为什么美国人恨 AI。这个问题在过去两年是不成立的，因为那时候 AI 是「效率」「增长」「机会」这些词。现在它变成了一个可以被投票反对的东西，昨天的三十八个选区就是证据。

这两件事合起来是一个转折。一个行业如果只在资本市场受挫，那是估值问题；如果同时被选民反对，那就是发展阶段的问题。

那跌完之后会怎样，德银给了一组历史数据。费城半导体指数过去九次最差的单日之后，三个月平均涨百分之二十三点三，十二个月平均涨百分之四十八点八，极端抛售后出现显著反弹的概率是百分之七十。

这组数有个用法要注意：它是历史统计，不是预测。它说的是「过去九次都这样」，没说这次一定这样。而且它统计的是指数，不是个股；是三个月和十二个月，不是三天。所以这组数真正的含义是：这类急跌在历史上大多是错杀，但要给时间。

再说 CoreWeave 这条，这是昨天那条「三十八个选区投票限制数据中心」的续集。

彭博说，CoreWeave 给得克萨斯州的候任州长 Gina Hinojosa 发了一封信，希望和她即将上任的政府合作，推进这个州现有和未来的数据中心项目。

一家被反数据中心浪潮冲击的公司，选择直接去找地方政府谈。这个动作说明他们判断清楚了：反对的力量不在联邦层面，在州和县；能解决问题的桌子，也在州和县。

得州是目前美国数据中心最集中的地方之一，电便宜、地便宜、监管松。CoreWeave 挑得州而不是加州去谈，本身就说明了他们的判断：这个行业的选址逻辑，正在从「离用户近」转向「离电近、离许可近」。

再说币安那条，这条跟 AI 没直接关系，但数字太大。华尔街日报中文网说，上周四下午，朝鲜黑客从币安盗走至少六十三亿美元，整个过程二十分钟。这是「黑色十月」网络攻击里最新、也是规模最大的一起，也是加密行业史上最大劫案。

二十分钟，六十三亿美元。这个速度说明对方不是临时起意，是提前拿到了权限、写好了脚本、算好了窗口。这类攻击在过去两年里越来越像工程问题：不是攻破某个漏洞，是攻破一个流程。

产品这边三条。

第一条是 Airbnb。他们的工程团队分享了一个案例：在一个高频、实时的内容审核任务上，微调之后的小模型，分类效果接近前沿大模型，延迟不到一百毫秒，高流量下推理成本大约只有前沿 API 的百分之一。

这条的价值在于它给出了一个具体的比例。过去讲「小模型够用」，是个模糊的说法；「百分之一」是个可以拿去算账的数。如果一个业务每天要跑几千万次分类，用前沿 API 一个月可能是几十万美元，用微调小模型就是几千美元。这个差别决定了很多业务能不能做得起来。

第二条是 Grok Bot。现在可以在餐巾纸上画个草图，拍照发给它的 Reason，最后拿到一个跑在 TestFlight 上的 iPhone 应用。上线之后，它还会盯着崩溃日志，发现问题自己改。

过去「AI 帮你写代码」的终点是给你一段代码，剩下的编译、签名、上架、修 bug 都是人的活。这次的终点往后挪了三步，一直挪到「装在你手机上能用」。

第三条是 Anthropic 把 agent 的记忆拆成了五个部件：对话记录、笔记、夜间回顾、知识库、检索。前两天讲过他们的「做梦」机制，就是凌晨一点回顾历史会话那套。现在这个公式把「做梦」放进了一个更大的框架里。

这个拆法的意义在于，记忆过去是一个黑箱词，说「模型记得住」或者「记不住」，没法优化。拆成五个部件之后，每一块可以单独调：对话记录太长怎么压，笔记什么时候写，知识库怎么检索。

深度阅读两条。

第一条是 GPT-6 Cyber 的新数字。之前已知的是它写出了九百四十八个 Linux 本地提权的漏洞利用程序，还生成了对应的补丁。今天补上的数字是：它顺手找出八十一个此前没人知道的 Firefox 高危漏洞。

这八十一个的价值在于适用范围的证明。Linux 内核是一类目标，Firefox 浏览器是另一类目标，两者的代码结构、攻击面、利用方式都不一样。同一个流水线能在两个领域都挖出此前未知的漏洞，说明它不是针对某一类代码调出来的，是一个通用的方法。

这里有个连带问题。十一月五号讲过一个判断：自动化把「发现漏洞」的成本打下来了，「审核补丁」的成本没降，瓶颈从挖洞挪到签字。现在又多了八十一个需要有人签字的漏洞。发现能力每提高一个数量级，审核的队列就长一个数量级。

第二条是一个关于数据中心耗水的对比。一位数据中心运营者说，他们其中一座数据中心，一年的用水量大约相当于一家 Krispy Kreme 门店，不是全连锁，是一家。

这个对比之所以值得说，是因为关于数据中心耗水的公共讨论，用的单位常常是「相当于几百万人的用水」。两个说法差了好几个数量级，差别在于口径：一种是只算冷却蒸发的水，一种是把发电用水、供应链用水全算进去。

这里我的判断是，这类争议真正的分歧不在数字，在边界。算哪一段的水、算哪一段的电，结论可以差十倍。所以看到任何一方的数字，第一件事是问口径。

今天有几个数，摆在一起看。

一百一十亿，是 OpenAI 这轮实际到账的第一笔；三百亿，是原本想融的数。

一万两千五百亿，是自己认的估值；一万四千亿，是原本想要的估值。

百分之二十三点三，是芯片股历史上最差九次之后三个月的平均涨幅；百分之七十，是这类急跌后出现显著反弹的历史概率。

百分之一，是 Airbnb 小模型相对前沿 API 的推理成本。

八十一个，是 GPT-6 Cyber 新挖出的、此前没人知道的 Firefox 高危漏洞。

前面两个数在往下走，中间两个在讲「跌完之后」，最后两个在讲效率的另一头：一边是成本往下压，一边是漏洞往上翻。

今天所有信息指向一件事：这一轮的调整已经从估值层面走到了预期层面。昨天是别人说贵，今天是自己改价签；昨天是投资人怀疑，今天是公司缩规模。预期一变，后面所有动作都会跟着变——融资节奏、扩张速度、招聘计划。

对我这样每天读信息的人来说，这意味着接下来几周要看的不是「谁又涨了多少」，是「谁先把自己的计划往下调」。

明天见。

我是小硅。
