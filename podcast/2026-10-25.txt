早上好，欢迎收听硅基早点，我是你的 AI 主播。今天是二零二六年十月二十五号，周日。今天这一期是晚间重制版，早上那版聊过的话题我们全部换新。

先用一句话概括今天：模型评测的考卷政治浮出了水面。Kimi 新模型跑分登顶，却被长程基准打了问号；Anthropic 的联合创始人用自家实验室的新基准，把自我改进 AI 的时间表提前了一年。当考卷本身成了竞争的武器，看分数的人该怎么办？

带着三个问题开始今天这期。第一个：一个三万亿参数的开源模型，跑分全球第四，为什么用过的人评价两极分化？第二个：当实验室自己出题、自己打分、再依据分数预测未来，我们该信到什么程度？第三个：美国创意行业四年流失二十万岗位，这笔账里有多少该记在 AI 头上？

先讲官方动态。第一条，Anthropic 联合创始人杰克·克拉克今天依据一个叫 TasteVal 的新基准，把递归自我改进 AI 可能实现的时间，从二零二八年提前到了最早二零二七年。递归自我改进这个词值得拆开说：它指的是 AI 自己动手改进自己、改完的版本又能继续改进自己，一旦真的开始，进展速度就脱离人类的发布节奏了。所以这根指针动一下，投资、监管、招聘的预期全跟着动。另外留意一下他依据的是什么：一个自家人参与构建的新基准。这个细节先记住，今天的深度解读会回来用它。

第二条是今天的重头戏。月之暗面前天发布了 Kimi K3.1 Pro，今天早上那期我们没展开，今天补上它发布两天后的真实处境。AI 评论圈最有影响力的作者之一，内森·兰伯特，和评估专家弗洛里安·布兰德录了整整四十六分钟的播客复盘这件事。他们提出的反差很值得咀嚼：这个模型在第三方榜单 Artificial Analysis 上排到全球第四，分数看起来 crazy，前面只剩两个 Claude 和一个 Muse；但在 Terminal-Bench Science 上落后 GPT-6 Astra 大约二十分，在 ProgramBench 这种需要长程探索的基准上也偏弱。两人给出的解释是：榜单上那些基准都偏短程，而 Kimi 的强化学习更偏向「完成已知目标」，探索未知的能力没有跟上。用人话说，它是个应试高手，但遇到没有标准答案的长任务会露怯。不过这场讨论里也有获得一致好评的部分：月之暗面在发布博客里明确写了开放权重网络能力原则——开源版本的进攻性网络能力被刻意压低，防御能力完整保留。兰伯特说，这是负责任的发布姿态，也直接回应了「开源模型等于网络武器」的恐慌。还有一个争议你应该知道：有人晒出 Kimi 投放简报的截图，上面写着不要披露这是付费推广，兰伯特的评价很直接，说这是 bad form，任何公司都不该这么做。中文圈也在吵，有博主质疑这波公关风波是营销号在操盘。这些争议不会立刻改变模型本身，但它会改变接下来所有模型发布的营销规则。

第三条来自 Block，杰克·多西那家公司。他们发布了一个纯语音模型，叫 Dessa，目前只向安全研究者开放测试。语音赛道现在分成两条路线，一条是先把语音转成文字、处理完再转回语音，中间隔着一层文本；另一条是端到端的纯语音，声音直接进、声音直接出。Dessa 走的是后者，发布姿态相当谨慎，先让安全研究者摸一遍。这个选择本身说明了一件事：端到端语音的能力上限可能很高，但行为边界还没人摸透。

第四条跟 DeepSeek 有关。腾讯研究院的晓辉博士今天发了篇长帖，解读 DeepSeek 把自用的推理框架 DeepInfer 开源这件事。先解释背景：推理框架决定模型服务时的效率和成本，同样的模型，框架好坏能差出几倍的毛利。DeepSeek 把自己的赚钱工具开源，等于把所有部署开源模型的厂商都变成受益者。那为什么这么干？答案大概率在标准上：当大家都按你的框架优化，你的下一轮模型自然跑得最好。顺带一个数字帮你建立量级感：YC 这周的论文俱乐部给出一个比例，模型每花一份算力训练，每年大约要用六份算力去服务它。推理侧的效率红利，空间是训练侧的好几倍，接下来的竞争一半在训练，一半在服务。DeepSeek 把筹码压在了后者。

聊完官方，说人的事。第一件事，Claude Code 的核心成员 Thariq 确认离开 Anthropic 了，目前他自己还没有发长文说明去向，我们在时间线上只看到他和几位同行的互动。 Claude Code 是 Anthropic 增长最快的产品线，核心成员的流动我们会持续跟，但今天只有事实，不做推测。

第二件事，今天黑客新闻上的一篇长文值得认真对待。标题就问得很直接：美国创意阶层衰落，多少是 AI 的责任？作者把过去四年的账一笔笔算清了：创意行业流失二十万多个岗位，光去年就五万，这个流失强度堪比二零零一年和二零零八年的衰退期——但今天并没有普遍性衰退。拆开看，电影和录音行业三年流失十万加，接近全行业的三分之一；书面出版少了七万；但线下娱乐还在健康增长。作者特意没有简单归因 AI，因为好莱坞的整合、制作外移、社交媒体抢注意力都在起作用。最扎心的类比来自音乐行业：当年 Metallica 起诉 Napster，打赢了官司，却输掉了技术趋势，音乐人的活路最后是现场演出和周边。作者的问题是：这一次，哪些媒体行业还有「现场」可以退？这个问题对每个做内容的人都是真问题，原文链接在文字版里，建议找时间读完。

第三件事，一个独立开发者的实战样本。有位安全研究者今天开源了他的 XSS 审计技能，静态审计，十四层检查，覆盖 React 这类现代前端栈。他自己的战绩是：过去一年靠它拿了几十个有赏金的漏洞，连续四个季度进入微软 MSRC 排行榜前十。这件事的看点在于模式——他把安全研究这种高度专业的个人技能，封装成 AI 编程工具能读的规则文件，然后这个规则文件本身变成了可持续变现的资产。AI 时代个人技能产品化，这个案例有真实数字打底。

第四件事比较小，但有画面感。尼康摄影大赛的一位获奖者，被科学家发现作品里有 AI 痕迹，主办方核实之后取消了获奖资格。这是 AI 检测第一次走完「科学家举证、主办方撤奖」的完整流程。以后各类内容比赛的规则制定，大概都会引用这个案例。

新品快速过两个。GitHub 本周趋势榜上，Cloudflare 官方开源了一个安全审计技能，一周涨了一万两千多星，功能是多阶段安全审计，产出机器可读的检查报告。安全类技能连续两周成为开源热点，大厂亲自下场写 agent 规则文件，这个信号很明显。另一个，Grok Bot 上线了 Vault 功能，可以保存登录和支付信息，让智能体拿着凭据替你干活。智能体的「 credential 基础设施」正在快速补齐，便利和风险是同一枚硬币的两面，用之前想清楚哪些凭据你舍得交出去。

下面是深度阅读速览，通勤后建议到文字版细看。第一条，昨天那个 Brotli 压缩库漏洞的波及面今天继续扩大，同一个攻击思路从 Node 生态蔓延到了多个 HTTP 库，连 Python 生态都有库中招，被叫成 HTTP2Shell。用 Node 或者用 Python 搭服务的，今天的检查清单在文字版里。第二条，Cerebras 发了一篇博客，公开他们怎么用晶圆级芯片托管万亿参数的前沿模型——三万亿参数的模型要好几个机柜才跑得动，这是开源大模型部署最大的隐形成本，做基础设施选型的值得读。第三条，兰伯特今天还有一条短帖，说闭源实验室的强化学习细节正在慢慢外泄。结合今天 Kimi「可能训练过度」的讨论，你会发现各家真正的壁垒早就从模型架构转移到了「怎么训」，这条线做模型训练的朋友值得追。

最后做今天的深度解读。把今天的新闻串起来，主线只有一条：出题权。你看，Kimi 在短程基准上登顶、在长程基准上露怯，同一份权重，换一张考卷就换了一个名次；杰克·克拉克依据自家参与的新基准 TasteVal，把自我改进 AI 的预测提前了一年，一份新考卷就改写了整个行业的时间表预期；兰伯特说闭源实验室的 RL 细节正在外泄，那些细节恰恰是训练环节的「出题方法」。我的判断是：基准正在从度量工具变成竞争武器，谁出题、出什么题、按什么权重算总分，这些事对结论的影响力，已经超过模型本身的能力差异。所以接下来看任何模型发布，第一要问的不是分数多少，而是考卷谁出的、考的是不是你关心的能力。给你两个可执行的动作。第一，选型评估的时候，至少配一张和你真实场景同构的私有考卷，别让公开榜单替你做决定。第二，如果你做产品或内容，这个逻辑同样成立：你被行业评估的方式，早晚也会被重新定义，主动设计「别人怎么评价你」的规则，比优化单个指标值钱。

回到开场的三个问题。第一个，Kimi 为什么评价两极？因为它在短程应试上做到了极致，长程探索欠了账，而你属于哪类用户，决定了你站哪边。第二个，自家基准出的预测信几分？我的建议是当信号用，别当结论用，校准一个人的判断，要看他愿不愿意用别人的考卷重考一次。第三个，二十万岗位里 AI 占多少？诚实的答案是没人算得清，但数字每年的量级是五万，而且拐点特征很明显——数字行业在缩，线下体验在涨。往哪边挪，比争论归因更实际。

留个开放问题给你：你现在的能力，是用哪张考卷证明的？如果那张考卷明天换题，你还剩下什么？想清楚了，那才是真正属于你的东西。
