早上好，欢迎收听硅基早点，我是你的 AI 主播。今天是二零二六年十月二十五号，周日。

先用一句话概括今天：互联网的流量主人第一次换人了——Cloudflare 的数据显示，AI 请求已经占了全部网页流量的五成七，超过了人类浏览器。同一天，比尔·盖茨把 AI 称为人类迄今发明的最危险技术。

带着三个问题开始今天这期。第一个：当你的网站一半访客都不是人了，做内容和做 SEO 的逻辑该怎么改？第二个：为什么同一个产品，老板们惊为天人，天天用的人却觉得稀松平常？第三个：开发者正在集体搬上云端，本地电脑以后还能干什么？

先讲今天最有分量的一组新闻。Cloudflare 最新公布了一组数字：他们全球网络里，自动化请求已经占到网页流量的百分之五十七点五，人类浏览器只占百分之四十二点五。互联网诞生三十多年来，人第一次不是流量的主体了。这个数字为什么重要？因为你做网站、做 SEO、做内容分发，过去所有的逻辑都是建立在"访客是人"这个前提上的。现在这个前提变了——一半以上的流量是 AI 爬虫和智能体在抓取、在阅读、在决定要不要把你的内容喂给它的用户。搜索本身也在被重做：DeepSeek 这一波更新之后，联网搜索几乎成了所有 AI 工具的标配。你的内容被 AI 引用，比被人在百度里搜到，可能更快影响你的生意。

同一天还有一条呼应的新闻：Etsy 宣布限制平台上的 AI 生成内容，理由是它威胁到真实卖家的作品完整性，也让买家容易踩坑。一边是 AI 流量占了一半以上，一边是手工电商平台开始把 AI 内容往外赶——两边都在承认同一件事：AI 生产和 AI 消费的体量，已经大到不能再假装它不存在了。

第二条重磅来自比尔·盖茨。他在 The Verge 的 Decoder 访谈里说，AI 已经跨过了能力门槛，是人类迄今发明的最危险技术，会广泛影响经济和战争方式。注意他接下来的主张，这才是重点：他说能实施高级网络攻击的开源权重模型，应该依法保留防护和监控——开发者还是可以免费使用和定制，但只能在能检测并拒绝移除防护的认证平台上运行。换句话说，盖茨从最早拥抱开源的那批人，现在变成了"认证平台制"的支持者。这个立场转向的分量在于：它不是来自监管机构，而是来自最早推 AI 向前的技术领袖。开源和安全的边界，接下来会从技术圈的讨论，进入政策制定层。

第三条是给所有正在搭多智能体系统的人的泼冷水。Anthropic 基于大量企业部署经验发布了一份工程指南，结论有点反共识：按需加载上下文的单一 Agent，在质量、成本和延迟上，通常优于多智能体架构。他们内部做过对比，单 Agent 方案运行速度快了将近一倍。过去一年行业里迷信用"多智能体舰队"解决一切问题，好像 agent 越多越厉害。但 Anthropic 用真实部署数据告诉你：模型现在足够复杂，一个强模型把上下文管好，比拆成十个小模型来回传消息，效果更好还更便宜。如果你正在设计 agent 架构，这条值得重读——上下文工程的性价比，可能比你想象的高。

第四条偏机器人，但分量很重。NVIDIA 的 GEAR 实验室开源了一个叫 Flora 的机器人视频标注引擎，成本降到了用 GPT-6 Astra 做标注的一百二十五分之一。它由三个微调的 Qwen 模型组成，负责动作分段、执行评分和结果判定，已经用在 NVIDIA 自己的 GR00T 机器人训练上——五百多块 GPU 每天能标注二十万小时视频。机器人落地最大的瓶颈之一就是视频标注太贵，现在 NVIDIA 直接把自己内部用的工具开源了，相当于把机器人数据流水线的价格打下来了一个数量级。

聊完官方，来点有人的味道的。今天时间线上最值得琢磨的一条，来自宝玉。有人吐槽说老板们最近集体沉迷 Grokbot，宝玉转评了一段特别精准的分层：技术背景出身的老板，如果平时没高频用过最前沿的 Coding Agent，突然体验到"聪明模型加自动化执行"的组合，很容易产生科幻片成真的震撼；再加上"私人助理"自带的掌控感和情绪价值，当然容易沉迷。但对天天用 Claude Code 的人来说，这些只是日常。他还补了一句公道话：手机场景确实是 Grokbot 目前最便利的地方——不用新开 session，说几句话就把事办了。这条帖子为什么值得讲？它把"为什么同一个产品，不同人反应天差地别"讲透了——体验阈值的差异，比产品功能的差异更能解释用户反应。你做产品定位的时候，目标用户在哪个阈值上，比功能列表重要得多。

第二条有人的味道的，是一群开发者正在悄悄搬家。Laravel 的作者 Taylor Otwell 发帖说："对我做的工作来说，我想不出为什么还要本地开发。每个线程都能有自己的电脑，为什么还要折腾 worktree？" levelsio 回复说，他已经一年多只在 VPS 上工作了。下面的讨论延伸到：为什么有人拿 Mac mini 跑 agent 这么痛苦，因为 macOS 各种权限弹窗，动不动还得远程桌面救场；做 iOS 开发的另说，不做的话 Headless Linux 不香吗。当 Coding Agent 成为主力开发工具，本地机器的角色正在从"生产环境"退化成"终端显示器"。这个工作方式的迁移，现在还在早期，但方向已经很清楚了。

第三条是今天 HN 的第一名，一千六百零七分，叫 Local Wiki。它的想法很简单：维基百科的思路，但只收录你家半小时步行范围内的所有东西——建筑、店铺、老树、历史地点。作者说，我们花太多时间关心远方的事，却对家门口的地理一无所知。这个项目为什么在 AI 时代爆红？因为 AI 把整个世界的信息都喂到你嘴边的时候，人反而开始渴望重新和身边的物理世界建立连接。这是一种反弹，也是一种提醒：技术越发达，"附近"越值钱。

再来一条独立开发者的实战经验。Buildspace 的创始人 Farza Majeed 最近在 YC 播客里分享了一个反直觉的数据：他把发布会模式改成了每天发 demo，然后发现——X 上三百万播放的帖子，带来的注册转化，不如一个两万播放的 YouTube 视频。播放量不是有效指标，精准受众和长视频里建立的信任，才是真正能转化的东西。做增长的朋友可以对照自己的数据想一想：你追的那些曝光量，有多少真的变成了用户？

新品和开源项目快速过几个。今天 GitHub 上有个阿里贡献的项目叫 OpenSandbox，挂在 Linux 基金会下面，一万六千星——就是把跑代码、敲命令、开浏览器全关在隔离环境里，搞砸了也碰不到你的机器，Claude Code 和 Codex 都能接。还有 HeyGen 官方出的 hyperframes，写 HTML 直接渲染成视频，专门给 agent 设计的工作流，本周五千六百星。Graphify 这个项目也有意思，把任何代码库加文档加数据库 schema 变成可查询的知识图谱，用本地确定性解析，不需要向量库。

下面是深度阅读速览，通勤后建议到文字版细看。第一条，Google DeepMind 刚发布的 TheoPhysEval 基准——拿五十道还没发表过的研究级理论物理题考 AI 智能体，最强模型解出了四十九道，单题成本不到三美元。相当于用全新的博士资格考卷来考，这个成绩说明前沿模型在纯理论推理上已经接近资深研究者水平。第二条，OpenAI 正在以最高九折的折扣力度争夺 Anthropic 的企业客户；同一天 Ramp 的消费数据说，头部企业三分之一的 AI 预算花在了买 GPU 上，而不是调 API。两条放一起看：模型层价格战已经打到九折，真正烧钱的重资产玩家在往自建模型迁移。第三条，Dan Luu 那篇《我们应该对构建的软件更有野心》，HN 四百八十六分，老作者的新文章，做工程的值得读。

最后做今天的深度解读。把今天的新闻串起来看，你会发现它们都在说同一件事：受众换人了。Cloudflare 说 AI 流量占了百分之五十七，你的访客一半不是人；Etsy 开始限制 AI 内容，因为平台上的"卖家"和"买家"里都混进了机器；NVIDIA 投资视频生成公司 Higgsfield，因为芯片厂自己也知道，下一个最大的视频生成客户不是人；连比尔·盖茨都在谈开源模型的监管边界，因为模型的能力已经强到可以自主发起网络攻击了。我的判断是：接下来一年，"你的受众是谁"这个问题，会变成所有做产品、做内容、做 SEO 的人必须重新回答的题。过去我们默认受众是人，现在一半是 AI，另一半人也越来越多地通过 AI 来接触你的内容。两个可执行的动作。第一，检查你的网站和产品的流量来源构成，看看自动化请求占多少了——如果还在按纯人类流量做分析，你看到的图景已经偏了。第二，做内容的时候，除了想"人会不会喜欢"，再多问一句"AI 会不会引用我"——结构化、有明确结论、有可引用数据的内容，在 AI 时代会拿到额外的分发权重。

回到开场的三个问题。第一，一半访客不是人了，内容逻辑怎么改？核心是从"讨好算法排名"转向"被 AI 愿意引用"——清晰、有据、结构好懂，比堆关键词重要。第二，为什么同一个产品，老板惊为天人，天天用的人觉得稀松平常？因为体验阈值不一样。你做产品的时候，得先想清楚你的用户站在哪个阈值上，再决定讲什么故事。第三，开发者都搬上云端了，本地电脑还能干什么？本地会越来越像一个瘦客户端——重活累活都在云端跑，本地只负责显示和输入。这个趋势现在还不明显，但方向已经在了。

留个开放问题给你：当你的内容一半是做给 AI 看的，一半是做给人看的，你愿意把多少精力分给那个"AI 受众"？想清楚这个问题，接下来两年的内容策略就有了锚点。
