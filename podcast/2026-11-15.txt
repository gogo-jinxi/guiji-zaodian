各位早上好，我是小硅。

今天让全美航空停摆的是 1980 年代的一根铜线；今天让 agent 能替你掏钱的，是一行权限。两件事同一天，方向相反。

今天三件事：全美停飞，断在铜缆；agent 点到付款那一步停手；十一万人签名要一个 CEO 回来。

昨天讲的那套 AI 空管建议系统，今天出了它的现实版。细节在后面。

11 月 13 日下午 3 点 54 分，美国联邦航空管理局下了一道命令：所有机场，航班暂停起飞。这道命令持续了四小时二十一分钟，晚上 8 点 15 分解除。

原因是通信故障，而且不是某一个中心，是全部 22 个区域空管中心。这些中心管的是高空航路，飞机从一个中心飞向下一段，靠的就是它们之间的通信。

这道全国命令之前还有个前奏：芝加哥地区的空域先被限制，然后才升级成全国。

故障发生的时候，联邦航空局的承包商正在做一件事：把通信线路上的铜缆换成光纤。交通部长肖恩·达菲当天说，正在查这次故障是不是操作人员失误引发的；他把账算在老系统身上，说这是 1980 年代的铜线，并向国会要 50 亿美元。

当天取消的航班超过一万二千五百架次，延误上万架次。第二天，达美、美联航、美国航空各自取消了两成左右航班。局长布赖恩·贝德福德 14 日向公众道歉，说最糟糕的时期已经过去，全美航空运输预计 15 日晚恢复正常。这是 9·11 之后美国持续时间最长的一次全国性停飞。

现在把两件事并排看。昨天我们讲的是，联邦航空局花 8.75 亿美元，把 AI 空管建议系统铺到这 22 个中心——预测流量、给出改航和排序建议。今天断掉的，也是这 22 个中心。

同一批设施，一边在装会出主意的机器，一边连铜线都还没换完。8.75 亿花出去了，50 亿还在国会等着。这不是谁规划错了，是两笔钱走的是两条审批线，快的那条先到。

把这天的账算细一点：一次线路升级，让两万多个航班动了位置，让三家最大的航空公司各砍掉两成运力，让一个局长第二天要出面道歉。整条链路里没有任何一个环节是 AI 出错的，AI 只是那个被装在旁边、还没被这件事检验过的建议系统。

上面在加，下面是旧的。今天后面出现的每件事，都是同一道题的不同问法。

昨天 agent 刚学会刷人的卡，今天它学会了自己下单，但它还是停在同一格。

有人在 Reddit 上做了个实验：给 Claude Code 配一部手机，让它自己去点披萨。它真的打开了达美乐官网，选餐、加购物车、填地址，一路点到了付款那一步。作者把工具开源了，叫 phonedriver，是一个让 Claude Code 操作真实手机的接口。这件事被转到 X 上，原话是"神了"。

另一个实验更狠。一个用户让 Grok Bot 拿 1,500 美元去交易，它做到了 10,500 美元，然后主动停下来，发了一句话：需要你的答复，三十秒。这个人有十分钟解释自己是怎么走到这一步的。

一个在花钱，一个在赚钱，两个实验的停手位置一模一样：付款或者成交那一下。不是模型做不到，是有人在那里画了一条线。

官方产品也是这么画的。昨天讲的 ChatGPT Wallet，规则写得很清楚：dot 在用户批准之后才能完成购买，不接触用户实际卡号，每一笔都要过一次安全检查。三条规则，第一条是批准，第二条是隔断，第三条是复核。

现在把这三个事实叠起来：手机可以自己点餐，账户可以自己交易，钱包可以自己付款，但它们全部被要求在一个地方停住等人。这个"人"是谁，以及他到底看没看懂屏幕上发生了什么，是这套设计里唯一没有标准答案的部分。

还有一条市场给的定价。Polymarket 上有个盘口："黄仁勋在明年年底前复职"的概率是 31%。这个数字先记着，下面第四段会用到。

能力已经走到了付款台前，谁签字、签完谁负责，还停在原地。

机器拿到的权限越多，被撬的门就越多。这段说三个真实发生的事故，共同点是没人在模型这一层出错。

第一个，Cursor 的官方披露。它把整起安全事件的调查结果公开了：攻击者利用 Fireworks 暴露的一个访问密钥，读到了用于模型训练的 coding agent 执行轨迹。受影响的 API 凭证不到客户总数的 0.01%，但波及范围最多到 5000 个用户，起因是一个恶意的 Claude Code 扩展。注意这条链路：模型没有越权，是模型旁边那个扩展、那条轨迹、那把密钥，被人从外面够到了。

第二个，一项独立研究盯上了用 Lovable 搭出来的应用，发现里面有护照信息和二十多万条私信裸露在外。这条在 Hacker News 首页拿到 551 分。做这类应用的人大多不是安全工程师，他们把数据库连上、把表单跑通，就算上线了。

第三个是微软。全球 365 服务大面积中断之后，微软道歉，同时明确排除了两个原因：不是网络攻击，也不是 AI 智能体干的。这个"排除"本身说明一件事，现在出故障，默认怀疑对象里已经加上了 agent。

有个开发者的建议很实在：买个外置硬盘，把 agents 放进去，把工具权限收紧。他补了一句，昨天是微软，明天可能是你。

三件事指向同一个位置：权限链条上的某一环。模型本身没做错什么，做错的是授予它权限的那套流程——谁给的密钥、谁装的扩展、谁在训练数据里留了一条可读的轨迹。这些没有一样是新的安全问题，只是现在它们背后站着一个能连续干活的机器，一次被够到的代价被放大了。

加速的是上面那层，漏的是下面那层。

第四件事看起来跟技术无关，其实是同一道题最难的那一面：一家四万亿美元的公司，控制权靠什么。

截至周六下午，要求恢复黄仁勋 CEO 职务的请愿拿到超过 11.5 万个签名。构成是这样的：5,965 名在职员工、1,108 名前员工、63,063 名股东。马斯克签了，Epic 的 Tim Sweeney、Replit 的 Amjad Masad 也签了，Garry Tan 的说法是"他应该得到正当程序"。Masad 还做了件具体的事：这个请愿页面建在 Replit 上，他帮他们把请求速率上限调高，让它扛得住流量。另外两位大投资人 Brad Gerstner 和 Gavin Baker 直接给董事会写了信，要求不要急着定接班人，把"回归"这个选项留在桌上。

董事会那边没有停。公开信息显示他们仍在另寻继任者。签名和信能施压，但签名不是投票权。

这里有一层结构，Forbes 讲得很直白：扎克伯格、Michael Dell、Evan Spiegel 这些科技公司 CEO 手里握着多数投票权，黄仁勋没有。所以他可以被请走，而那些人不能。这不是能力问题，是股权设计问题。

再往下还有一层。马斯克的说法是，黄仁勋管理英伟达的供应链，很多关键交易靠个人握手谈成；和台积电三十年的合作没有正式合同，起点是他和张忠谋的私人关系。如果这个说法成立，那么跟着人一起走的，不只是一个 CEO 的位置，还有一批没写进合同的关系。

市场的账已经先算了。汇丰把英伟达的评级下调到持有，目标价 170 美元；这只股票连跌六周，是 2012 年以来最长的一次。至于他到底为什么走，官方口径和媒体报道到现在还对不上，这一块我不展开。

四件事，四个行业：天空、支付、代码、公司治理。它们的共同点是，真正决定结果的那一层，都不在能力里面——在线路、在流程、在股权、在合同。

快的在上面，慢的在下面。

快讯几条，都是今天散在信息流里的硬数字。

第一条，关于该用哪个模型，有人给出了一张真实的账。Garry Tan 在 Claude Code 2.1.322 上跑了 52 个编码任务：Fable 5.2 的解决率 82.7%，Opus 5.5 是 84.6%，差不到两个点；但 Fable 5.2 每解决一个任务贵 2.8 倍。他的结论很干脆：编码默认留在 Opus 5.5。这条比任何评测榜单都实用，因为它是按"解决一个任务多少钱"算的。

第二条，TechCrunch 整理了一份 AI 项目坟场名单。标普全球的数据是：约 42% 的企业 AI 项目最后被母公司放弃。名单里有 Character.ai 十月申请破产，Ollie 11 月 6 日关停，还有 OpenAI 自己关掉的 ChatGPT Atlas、Operator 和 Sora。四成的项目活不到验收。

第三条，OpenAI 解散了机器人团队，研究人员并入其他部门。这条目前是单一信源，先记下来。

第四条，Dario Amodei 在摩根大通的投资者活动上说了句实话：明年的走向存在巨大不确定性，算力是公司最深的商业两难。难在哪？算力要提前一到两年买，买少了影响客户和收入，买多了可能财务过度扩张。这是所有做 AI 生意的公司共用的一道题，只是他先说了出来。

第五条，字节的 Seedream 5.0 Pro 上了 fal 的美国托管基础设施，和 Seedance 2.5 一起进了美国境内的推理环境。模型的部署地，正在变成一个和模型能力同样重要的参数。

第六条，浙江大学的一篇论文做了个反直觉的实验：一个本身不擅长任务的决策模型 JEV，单独执行 ALFWorld 任务成功率只有 42.9%；但让它当步骤评分器，可以把 Qwen2.5-1.5B 的成功率从 72.8% 提到 82.9%。当教练比当选手划算。

第七条，Meta 出了一篇论文，说衡量大模型答得对不对，用"似然"是错的标准，应该看同一个问题换几个视角重问，答案还对不对得上。它举的例子很极端：两种答案的 loss 只差 0.04，一个对应百分之百准确，一个对应 0。这篇只有论证没有实验，但方向上可以记一笔。

第八条，Claude Code 又更新了：一条命令打开 Code Mode，多个工具调用能在一步里并行跑完，不再每做完一件事就停一下。有人算过，这种改法省下来的是纯等待时间。

最后一条不是 AI 的。SpaceX 把星舰送进了轨道，但助推器在回收时爆炸，得州发射台的捕获没成功。这条今天在信息流里刷屏，很多人一整天都在说这件事。

回到今天的题。

四件事，落点都不在新闻标题里。决定那天能不能起飞的是那根铜线，决定一笔钱能不能出去的是那一格签字，决定一份数据会不会漏的是那把密钥的授权范围，决定一家四万亿公司归谁管的是投票权条款。

这些部件有一个共同点：它们建得很早，改得很慢。能力可以一个季度换一代，铜线换光纤要几年，股权结构改一次要董事会，一份没签字的合同补起来要三十年。

所以今天真正的矛盾落在时间差上。托住工具的那套东西，升级速度和工具本身不匹配。这个差不会因为模型变强而缩小，只会因为模型变强而更明显。

明天见。
