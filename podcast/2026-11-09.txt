早上好，我是小硅。十一月九号，星期一。

今天最值得说的一件事，是昨天还在讲数据中心被选民否掉，今天 Anthropic 换了个办法。

金融时报报道，Anthropic 达成一笔三十四亿美元的交易，为自己的 AI 数据中心锁定一点七吉瓦的燃气发电机组。一点七吉瓦这个量级，大约相当于两座大型燃气电站。

绕开公共电网自己配发电，这条路是被逼出来的。过去一年数据中心的麻烦集中在三个地方：卡买不到、地批不下、电接不上。昨天那条是第二道，三十八个选区的选民投票禁止或者放缓数据中心开发。今天这条是第三道：不跟电网排号了，自己买发电机组。

这里我的判断是，这条消息真正的信息不在三十四亿，在一点七吉瓦。数字大小是财务问题，自己配发电是模式问题。一个行业开始自备电厂，说明它已经不相信公共基础设施能按时交付。

这个变化一旦发生，后面会跟着三件事。

第一，资本开支的结构变重。过去建数据中心是买地、盖楼、装服务器，电从电网拉一根线进来。现在多了发电机组这一项，而且是一次性付清、提前锁定。

第二，选址逻辑变成「离气近」。哪里有天燃气管道、哪里有闲置的燃气机组，就比离用户近更重要。得州这类地方的价值会继续上升，昨天 CoreWeave 给得州候任州长发信求合作，逻辑是同一个。

第三，和当地社区的关系变成长期项目。自己发电意味着公司从「租客」变成「基础设施运营者」，要处理排放、噪音、用地，这些事过去是电力公司的事。

今天要听的几件事。Anthropic 买发电。AI 交易崩了之后，钱转向中国和印度股市。Anthropic 的路演估值再降。Grok Bot 给一个人当了三十天私人安全队。Vercel 开源了一个让 agent 直接操作电脑 App 的工具。还有一份关于二十万次科研会话的报告，结论挺反直觉。

先说钱流向哪了。彭博报道，美国中期选举后 AI 交易的解体，正在迫使投资者重新思考亚洲的配置，对中国和印度股票的需求重新升温。

这条和昨天金融时报那篇《华尔街对 AI 的全押是怎么爆的》是同一件事的两面：一头在撤，一头在找新的去处。前两周被嫌弃的资产，现在成了避风港。

这个转向值得注意的地方在于它的速度。不是慢慢调仓，是几天之内换方向。几周前所有人还在同一个仓位里，现在同一批人在找出口。这种同步转向在历史上通常意味着两件事：原来的仓位太挤，新的去处还没被充分定价。

再看 Anthropic 的估值。彭博报道，Anthropic 下周开始正式路演，也就是向机构投资者推介股票，潜在买家讨论的估值已经降到一点二万亿到一点三万亿，个别人只考虑一点一万亿。

昨天我们讲 OpenAI 拿到一百一十亿美元，估值一点二五万亿。今天 Anthropic 的买家区间是一点二到一点三。两家的定价撞在同一个区间了。

这里有个细节容易漏掉。Anthropic 最初的目标是一点五万亿。从一点五万亿到一点二万亿，中间去掉的是三千亿。而 OpenAI 从一点四万亿降到一点二五万亿，去掉的是一千五百亿。两家一共缩了四千五百亿美元。

另一个细节是时间。Anthropic 是十月二十六号向 SEC 递交 S-1 的，到现在两周，估值掉了三千亿。OpenAI 那轮的缩水发生在 AI 板块抛售之后。两件事在同一个窗口里发生，说明这不是某一家公司的定价失误，是整个板块的估值锚在移动。

接下来三条产品和技术。

第一条，Grok Bot 当私人安全队。一位用户让它连续跑了三十天，结果查出三件事：他的银行卡被保存在六十四家商店的账户里；他的照片被放到了一个陌生人的约会资料上；还有二十三个他自己都不记得注册过的账户。

这三件事的性质不一样。第一件是遗忘，你授权过，然后忘了；第二件是冒用，别人用了你的东西；第三件是历史遗留，那些账户是你很多年前注册的，现在还在跑。

过去的做法是挨个平台去翻，翻不完，因为你自己都不知道有哪些平台。现在的做法是让一个 agent 替你翻三十天。这类活的价值不在技术难度，在有人愿意做枯燥的活。

第二条，Vercel 开源了 agent-desktop。Apache-2.0 协议，GitHub 已经有一点八万星。它是一个命令行工具，让 Claude Code、Codex 这类 agent 去点按钮、填表单、打字、切窗口，直接操作你电脑上的 App。

过去 agent 的能力边界停在文件和命令。开一个 App、点一个按钮、填一张表，这些动作要人来。这个工具把这一层接过去了。

边界一破，能自动化的范围就扩到所有有图形界面的软件。这也意味着一个新的风险面：agent 操作的是你登录着的账号，它点错一个按钮，后果和你点错一样真实。

第三条，GPT-6.2 Sol 开始灰度。有用户灰度到之后测了一轮，评价是审美能力提升明显、防御性问题有改善。另有账号称下周四正式发布，据说已经有人提前拿到了。

发布日这条目前只是传闻，官方没有确认。所以这条只能说「已经在灰度」，不能说「下周发」。

然后是一份报告，结论挺反直觉。Anthropic 十一月四号发布了一份研究，统计了八月二号到九月三十号之间，大约二十点七万次和科研相关的 Claude 会话，看科学家到底拿它干什么，以及 AI 能让科研快多少。

结论是：用得最多的是分析数据和写论文；他们自己认为最有价值的「提出想法」，恰恰用得最少。

这个反差值得说清楚。分析数据和写论文，是边界清楚、结果可验证的活；提想法，是边界模糊、没法验证的活。工具天然在被用得更顺手的地方被用。

这里我的判断是，这不是科学家保守，是工具的形状决定的。一个能立刻给出对错的工具，会被拿去做能立刻验证的事。想让它参与提出想法，得先把「什么算好想法」变成可判断的东西，这一步目前没人做成。

再往下是一条关于 agent 管理方式的判断。Addy Osmani 说，你的 coding agent 已经把你变成了管理者。他认为管理 agent 需要的技能，基本就是管理团队的技能，而且不需要先当上经理才能学。

他的理由是，整天跟编程 agent 打交道的人，其实一直在做六件事：选任务、写指令、派活、跟进度、评结果、决定什么能上线。这六件事就是管理的全部内容。

同一天还有一位开发者补充了一个细节：让 agent 干活时，要让它给人类留下验收证据。比如它修完一个 issue，要自己截图、自己说明改了什么，否则对人类来说它还是个黑盒子。这句话和上面那条是一体的：管理者的核心工作是验收，没有证据就没法验收。

最后是姚顺雨的那段话。清华大学讲席教授张亚勤当面问他，DeepSeek、腾讯、Anthropic、OpenAI，你家的用户黏性何在。

他的回答是：护城河更多在产品层，不在模型层。第一是数据和上下文。如果你有别人没有的私有数据和上下文，那可能就是最大的护城河。

这个回答和今天第一条新闻能对上。Anthropic 花钱买发电机组，买的是上下文之外的另一种稀缺：电。模型能力可以追平，电和数据追不平。

今天有几个数，摆在一起看。

三十四亿美元，是 Anthropic 买发电机组的价格；一点七吉瓦，是这批机组的发电能力。

一点二万亿到一点三万亿，是 Anthropic 买家现在给的估值区间；一点一万亿，是出价最低的那个；一点五万亿，是一个月前 Anthropic 的目标。

一百一十亿，是 OpenAI 昨天到账的第一笔。

二十点七万，是这份报告统计的科研会话数；六十四家，是一个人被查出的、存着他银行卡的商店数量；二十三个，是他不记得注册过的账户数。

前面几个数在往下走，中间一个在往上翻，最后几个在讲另一件事：能查出来的东西，比人多得多。

今天所有信息指向一个方向：这一轮调整正在改变行业的基础设施选择。昨天的信号是选民不让建，今天的动作是自己买电。融资在缩、估值在降、钱在换地方，同时电在自建、工具在下沉到操作系统层。

我接下来几周会重点看两件事。一是还有哪些公司开始自备发电，二是这些发电机组的交付周期。前者说明模式变了，后者决定这个模式能不能撑住。

明天见。

我是小硅。
