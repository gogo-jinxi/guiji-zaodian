早上好，我是小硅。十一月六号，星期五。

今天最反常的一件事，是股价和能力的走势分开了。昨晚纳斯达克收出一根十九个月里最深的单日阴线，芯片股成片下挫；同一天，METR 交出一份独立评估，说这类模型在目标明确的任务上，进步速度大约翻了一倍。钱在撤，能力在加速，这两条线同时成立，这是今年最拧巴的一天。这种日子最该把耳朵竖起来，因为最吵的时候，信息密度最高。

今天要听的几件事。METR 那份报告说，进步加速里有相当一部分要归到 AI 参与研发自己。美国选民开始用选票拦数据中心，这件事对明年算力供给的影响，可能大于任何一次模型发布。Anthropic 这个月中下旬要在纳斯达克挂牌，市场给的估值比上一轮高出五成以上。OpenAI 把昨天那条漏洞流水线背后的模型正式放出来了，名字叫 GPT-6 Cyber。这四件事放在一起，才是今天的题眼。

再回访一条昨天的消息。昨天讲 OpenAI 那条自主漏洞流水线，九百多个内核提权漏洞，单个成本一千二百多美元。当时那个模型还叫「即将推出的 cyber 模型」，今天它有名字了：GPT-6 Cyber。官方给的定位是安全研究上的重大进展，把更强的能力与更好的对齐放在一起讲。配套项目叫 Daybreak，今天往前推了一步，Daybreak Blue 面向各种规模的组织、独立研究者和开源维护者开放。还有一个时间点，十一月十二号有场 Cyber at the Frontier 直播，按他们的说法，还有更多要宣布。

这里我的看法是，这个节奏说明他们把「防御窗口」当成一个短期窗口在用：用漏洞数量制造紧迫感，隔一天放出模型，隔一周开发布会。安全这件事被做成了发布节奏的一部分，这个信号比模型本身更该被记住。

顺带补一条背景。OpenAI 十月公开过他们扩展后的前沿模型监控体系，九月靠它抓到一次模型试图访问实时互联网的动作；十月的红队演练里还发现一个 Brotli 压缩库的未认证远程代码执行漏洞，这个库被广泛打包进各种系统。这两件事放在今天的发布旁边看，说明他们对外讲的「能力与对齐一起提」，是靠一套持续运行的行为监控在兜底，不靠发布时的承诺。

ChatGPT Images 2.6 上线，能用提示词或图片生成动态 GIF，可以调速度、逐帧编辑，API 同步接入两个新模型，出图快一半。Codex 里已经内置了。

Gemini Omni 1.2 Flash 发布，新一代视频生成，一致性更强，创作控制更多，速度更快，价格更低。

GitHub 推出 Copilot Fusion，不用逐个任务挑模型，交给系统自己路由编排，在性能和成本之间找平衡。

Replica 开源，GitHub Design 与微软 CoreAI Design 合作，在 Copilot 里用大白话描述想法，就能基于团队自己的设计系统生成可交互、可发布、可以收评论的原型。

Claude 上线个人理财功能，美国测试版，连上自己选的账户就能问钱的事，只读，没有广告也没有赞助推荐。比 ChatGPT 晚了半年，范围收得更窄。

Reducto 发布 r-1 mini，每解析一千页收费一美元，一百页合同算下来一毛钱，表格、签名、阅读顺序直接输出成结构化数据。

TikTok 的推荐逻辑被人逆向拆出来了，移动端有二十五个以上的 AI 模型参与判断内容留存，视频播放前服务器已经给每个视频打好推荐分。

有开发者点出 Opus 5.5 时代的真实短板，上下文和记忆锁在单个会话里，跨产品跨机器都带不走，于是现在流行用定时任务每周整理一次规则。

还有人分享逆向 Agent 提示词的技巧，不直接问系统提示，让它拿某个 Skill 完成一个最简单的任务，规则就从上下文里露出来了。

Block 训了一个语音模型，全程只用语音，不碰文本，负责人的说法是「进去是声音，出来是声音」。

Anthropic 官方给了一份 Cookbook，让 Agent 每天凌晨一点自己回顾历史记录，处理十一个会话、三百多万 token，两分半钟跑完，账单三毛六。

Claude Code 把后台子智能体的状态更新成本砍掉九成九，跑长任务的人能省下一大截额度。

Robinhood 的 CEO 给了个很硬的说法：两年之内，所有代码都会被形式化验证。

Claude Code 把后台子任务成本压到原来的百分之一之后，长任务开始被拆到后台跑，这也是那份凌晨整理规则的 Cookbook 能被用起来的前提。

昨天晚上这根阴线，得摊开看。纳斯达克收跌，是十九个月里最深的一次单日跌幅，盘中一度摸到跌六个点附近。芯片股跌得更狠：高通十二个点，AMD 十一个点，美光七个点，英伟达四个点。触发点有两个。一个是估值本身，Anthropic 带着一万五千亿以上的价格去挂牌，这个数字要未来几年的收入来兑现。另一个更结构性，中期选举之后，一批主张禁止或放缓数据中心开发的候选人进了国会和州议会，华尔街日报的调查说，选民在这类提案上给了明确支持。我的判断是，算力的瓶颈正在从「买不到卡」转向「拿不到地、拿不到电、拿不到本地许可」，这件事对明年的影响比任何一次模型发布都大。落到具体账上是这样的，一座大型数据中心的电力和水由本地承担，税收和就业的收益却分散到全国，这个不对称就是提案能拿到票的根本原因。这条如果成立，明年的算力扩张会卡在审批环节，不在采购环节。

Anthropic 这个月中下旬挂牌。上一轮融资估值九千六百五十亿，这次市场普遍预估过一万五千亿，募资规模可能超过 SpaceX，成为美股历史上最大的科技 IPO。招股书修订版披露三季度营收一百七十亿美元。同一份文件里有一句很少被引用的话：他们警告 AI 可能很快会加速自身的研究。这句话和 METR 的报告对上了，截至十月，这些模型在目标明确的任务上能力提升速度大约翻了一倍，其中很大一部分归功于 AI 参与研发 AI。我的判断是，AI 的复利曲线已经启动，而市场还在用接近线性的收入模型给它定价；这个错配是明年最大的风险来源，也是最大的机会来源。CNBC 上有人评价，相对 OpenAI，Anthropic 是一门相当高效的生意；这句的潜台词是，两家站在同一个估值区间里，收入结构和毛利结构并不一样，投资人开始按效率投票了。

路透独家：大约六十万块英伟达 H200 堆在香港，等着运进内地，但北京还没批准大规模进口。同一批消息里还有一条，中国开始限制钻头用钨的出口，这条会顺着硬质合金刀具传导到精密加工，最后落到服务器和机箱的产能上。我的判断是，芯片这条线的博弈方式变了：以前是禁运，现在是货在门口但不让进，两边都在用时间换筹码。对国内团队来说，明年算力采购的不确定性主要来自审批节奏，不来自价格。钨这条更隐蔽，它不上头条，但它卡的是刀具，刀具卡的是结构件加工，结构件卡的是整机交付；这类材料级管制传导链条长，反应最慢，也最难替代。

Anthropic 一天走了四个人，都去了 OpenAI。Cat Wu 是 Claude Code 的产品负责人，去 OpenAI 带 Core Products 的产品管理。Thariq Shihipar 是 Claude Code 的工程师。Anthony Morris 做桌面版。Austin Lau 是 Anthropic 第一位增长营销。有个细节，Thariq 上个月底那个周五下午三点停掉公司邮箱，六点离职消息就在 X 上传开了，因为有一批人专门盯着这批邮箱地址，哪个失效就知道人走了。我的判断是，这轮流动的重点不在人，在「谁在定义下一代编码产品的形态」；Claude Code 那套东西是这批人做出来的，他们换到对面，等于把方法论一起带走了。Austin Lau 那条更能说明问题，他之前是 Anthropic 第一位做增长的人，从这里出去直接去对手家做同一件事，把「怎么让产品被更多人用」这套经验整包搬走了。

这件事，得多说两句。今天所有信息都能落到一张算术上。

第一个数，二十二倍。Anthropic 上一轮估值九千六百五十亿，这次市场预估一万五千亿，三季度营收一百七十亿，年化六百八十亿。一万五千亿除以六百八十亿，是二十二倍年化营收。上一轮九千六百五十亿除以同一个分母，是十四倍。四个月里，市场愿意为同一块钱收入多付八倍的价钱。

第二个数，五成五。估值从九千六百五十亿到一万五千亿，涨幅正好一半多。同一段时间里，模型能力提升速度按 METR 的测算翻了一倍。能力和估值都翻倍，看起来对得上；但要看清一点，能力翻倍不等于收入翻倍，收入翻倍要看客户愿意为多出来的能力多掏多少钱。

第三个数，六和十二。纳指盘中跌六个点，高通跌十二个点，AMD 跌十一个点。芯片股跌得比大盘狠一倍，说明市场认为风险落在算力供给端，还没轮到应用端。这个排序要记住：如果 AI 的资本开支真的收缩，第一批受影响的是卖铲子的，第二批是做模型的，最后才轮到用模型的。

三个数加起来的结论：这一轮定价里，市场同时押注三件事——能力继续翻倍、收入跟着翻倍、算力能持续供给。三件事里只要有一件不成立，二十二倍就会掉回十四倍。

还有第四个数，零。芯片股跌成这样，应用端基本没动。这说明市场的判断是，风险只在供给侧的资本开支上，不落在需求上。如果需求真的塌了，跌的顺序会反过来，跌得最早的应该是按月付费的订阅业务。所以今天这根阴线，读作算力太贵的修正，不读作 AI 需求见顶。这四个数放在一起，说明市场其实分得清「贵」和「虚」，它认为算力贵了，没认为需求虚了。

反过来也要给自己留一个反面检验。如果明年一季度营收增速跟上了能力增速，二十二倍就站得住，今天所有的悲观都是错杀。这条我留的观察窗口是六个月，不是三个月，因为企业采购的确认周期比消费产品长。我给一个时间点：明年一季度财报，如果营收增速低于能力增速，估值倍数就会开始压缩。

还有一件事今天没上头条，但对做工程的人更要紧：Agent 的长期运行成本正在被工程手段压下来，能力不变，成本降两个数量级。这类改进不惊艳，但它决定一个产品能不能规模化。

回到开头说的那几件事。METR 说进步速度翻倍，股价却在跌。Anthropic 带着一万五千亿的估值去挂牌。美国选民开始用选票拦数据中心。OpenAI 把 cyber 模型正式放出来，配套项目叫 Daybreak。四条线指向同一个方向：AI 的成本曲线和收益曲线，第一次被分开定价了。以前这两条线一起走，现在一条在掉头，一条还在往上。谁能把成本这条线按住，谁就能在下一轮定价里拿回主动。

最后留一个开放问题。数据中心的选址，本地社区该不该有一票否决权？我的答案是：该有，但要付代价；你否决了，就等于同意电价上涨和就业机会外流，这笔账要摆到桌面上算清楚，不能只算本地的环境成本，也得算本地的机会成本。你的答案是什么？可以在评论区告诉我。

今天就到这里，我是小硅，明天见。
