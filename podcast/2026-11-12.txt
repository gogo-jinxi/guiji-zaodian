早上好，欢迎收听硅基早点，我是你的 AI 主播小硅。今天是 2026 年 11 月 12 日，星期四。

今天这期有一条主线：谷歌发布了一个不写答案的模型，它唯一的工作是判断。

今天讲四件事：谷歌这个 Decisions API 怎么把判断做成商品；谷歌自己承认 AI 写前端停在 2019 年；斯坦福把智能体工程课的作业全部公开；还有 Fable 5.2 官方提示词指南里三组反直觉的数据。

先说一条回访。

昨天讲过 Anthropic 从今天起按所在地和雇主封禁中国区用户。今天这条又深了一层，不只按地理位置封，个人账号开始过 KYC 实名核验。有用户说，用了两年的 20X MAX 账号刚被封，原因是没做 KYC。同一天，另一边有人在分享防封教程，说自己拿新注册的 Gmail 直接注册 Claude、直接开 Max，一路丝滑，没有卡点也没有 KYC，这套教程迭代了两个月。

一个平台想把人筛干净，一群人想绕过去，两边都在这条线上加筹码。

今天最实在的一条发布，是谷歌的 Gemini Decisions API。

它和别的模型接口最大的区别是：它不写字。你给它一个问题，它不回一段话，只回一个判断——是或者否、选 A 还是选 B、这条内容放行还是拦下。

按官方口径，一次最多能问一千个问题，输入一百万 token 收 0.1 美元，输出不收钱。

这个价格得算一下。一百万 token 大概是几百页文本的量。拿它做判断，单次成本可以忽略不计。

配套的新模型叫 Gemini Decision 1，官方给的用途是三样：路由、选工具、安全分类。路由是用户问了一句话，系统该交给哪个环节接；选工具是 agent 面前摆着十几个工具，这一轮该调哪个；安全分类是这条请求合规还是不合规。

这三件事听着不起眼，但它们是 agent 系统里最费钱的三件事。一个 agent 每走一步都要判断一次下一步干什么，判断错了后面全错。以前这类判断也是交给大模型做，可大模型每次都要先写一段"我认为应该……"的推理过程，token 就这么一路烧掉。

现在这部分被单独拆出来，变成一个便宜的、只输出结论的接口。

我的判断：这条发布的分量不在价格，在于它承认了一件事——生成和判断是两种不同的活。写文章、写代码，那是生成；决定该干什么、该不该放行，那是判断。过去两年所有模型都在比生成，判断能力被塞在生成过程里，跟着一起变贵。谷歌把它拆开单卖，等于承认生成已经过剩，判断才是需要省着用的东西。

这条能证伪的地方我说清楚：如果三个月内没有第二家厂商跟进做同类接口，说明这条路只有谷歌在走，那它可能不是行业方向，只是谷歌自己的成本优化，不是判断这件事本身变便宜了。

再看几条快讯。

谷歌官方博客里有一句话被中文圈传得很广：AI 写前端，默认停在 2019 年的水平。原因是训练数据里塞满了十几年前的旧代码。修复办法是装一个 Chrome 的技能包，把 212 个现代 Web 特性喂进模型，通过率从 56% 提到 88%，装法是一行命令。

这事暴露的是一个更普遍的毛病：模型会写出看起来对、实际上用不了的代码。它不知道 2026 年的浏览器已经支持了什么，它只知道训练数据里见过什么。所谓"能写"和"写得对"，中间隔着一整个知识更新周期。

第二条，斯坦福这学期开了一门新课，叫 CS329Z，智能体工程。课程资料全部公开，讲座每天上 YouTube，两份作业开源。第一份作业是教你花几美元，从零搭一个类似 Claude Code 的东西。

这门课的分量在于它不空谈。第一讲就叫《什么是 AI 智能体，智能体系统详解》，中英双语字幕，后面全是动手搭和动手评。想真正搞明白 agent 怎么运转的人，这比读一百篇公众号直接。

第三条，jev 的创始人、instructgpt 的合著者 Diogo Almeida 发了一份 PDF，讲怎么给 coding agent 搭 harness，也就是模型外面那一层调度框架。他给的数字是：速度最高快 200 倍，成本最高低 400 倍。

这组数字得打折看，倍数是在特定任务上测出来的。但方向很扎实：同一个模型，外面那层框架不同，跑出来的效率和花费能差一个数量级。快和省不藏在模型里，藏在模型外面。

第四条，一个叫 Obscura 的 Rust 项目拿到 3.2 万星，做法是把 Chromium 整个踢出浏览器链路。以前跑浏览器 agent 或者大规模爬虫，要么被 Chrome 几百兆的内存吃干净，要么被全网反爬拦下来。它直接走底层重构，绕开这两件事。

第五条，扣子的企业版宣布退出。2025 年 7 月字节还高调开源 Coze Studio，一年多走到这一步。有开发者的评价是，这件事该给所有中国 AI 开发者上一课。

下面进入今天的重点。

Fable 5.2 出来第二天，今天最该说的不是它有多强，是官方那份提示词指南里的三组数据。

第一组：在代码库里加一句「这个代码库归你管」，agent 主动整合重复代码的比例，从不到 10% 涨到接近 50%。

第二组：加一句「任务没做完别停」，官方测试里 agent 干一半就提前收工的情况少了一半。

第三组是反过来的。官方图表推荐用最高一档的思考强度，但有人拿两个真实 PR 去测，发现代码 review 这件事，在次一档反而做得最好。官方推荐的那档，不是所有任务都最优。

三组数据放在一起，结论有点反常识：决定 agent 表现的，往往不是模型多聪明，是你有没有把职责说清楚。

「这个代码库归你管」这七个字，干的事是把 agent 从执行者变成负责人。它不再等你派活，它开始自己找重复代码整合。整合重复代码这件事，没明确指令的时候谁都不主动干，因为它不紧急、不显眼、干完了也没人夸。一句话改变的是动机结构。

「任务没做完别停」更有意思。agent 提前收工不是因为懒，是因为它认为"差不多了"。它没有人的那种"这事儿没完"的焦虑。你不给它标准，它自己就定一个低标准。

第三组数据反过来提醒一件事：官方给的推荐参数，是基于一批任务的综合最优，不是你那批任务的最优。拿官方图表当圣经，等于把别人的平均当成自己的答案。

这一组数据正好接上今天的头条。判断这件事，模型包不了全部。什么时候该停、这件事算不算做完、这段代码该不该合并，标准得人来定。谷歌把判断做成便宜接口，卖的是执行判断的速度，不是判断依据从哪来。

今天还有一条不那么显眼的消息，但和每个在用这类工具的人相关。

Claude 开始在账号层面做 KYC，也就是实名核验。有用户说用了两年的 20X MAX 账号，因为没做 KYC 被封。同一天，中文圈有人分享防封教程，说自己拿新注册的 Gmail 直接开 Max，一路通过，这套教程迭代了两个月。

这两条同一天出现，说的是同一件事：平台在收紧身份，用户在找绕路，两边都在加码。

平台为什么要这么做？昨天讲过按所在地和雇主封人。地理位置靠 IP 判断，可 IP 能换。网络层面封不干净，就只能往账号层面走，看这个账号背后到底是谁。

用户为什么要绕？因为这类工具已经是生产工具了。一个中文开发者用 Claude 写代码，不是因为好奇，是因为工作真在用。封掉的不是娱乐，是产能。

成本落在谁身上，得说清楚。落在那批合规使用、但所在地正好被规则覆盖的人身上。他们没做错任何事，只是位置不对。

我的判断：这条路走下去，会长出一个灰色市场——代注册、代实名、共享账号。这类市场一旦成型，风险不是被封号，是账号里跑的东西和实名身份脱钩，出了事找不到责任人。

这里的不确定处我得明说：KYC 到底覆盖到什么程度，官方没有完整说明，现在都是用户个案在拼图。有人被封，也有人一路通过，两种情况同时存在。

今天还有一场争论，我觉得该讲。

Fable 5.2 在 RoboDojo 的模拟双臂机器人测试里拿到 64.9%。有人拿这个分数去嘲讽李飞飞的 World Labs，说世界模型是骗局，Atlas 已经被 Claude 吊打了。

有位研究者专门写了反驳：这种比较搞错了研究问题。64.9% 是模拟环境、给定任务下的操作成功率；世界模型要回答的是另一件事——一个系统能不能在没见过的环境里建立起对物理世界的理解。两个问题的答案不能互相替代。

我同意这个反驳。分数高只说明这套方法在测试条件下有效，不说明另一种方法没有价值。拿 A 的考卷分数去否定 B 的研究方向，是最省事、也最容易传播的一种错误。

同一天还有另一条反调。有人说 Fable 5.2 一夜之间做出很多页游，看着像 3A，可真正的玩家一上手就看出破绽。原因很实在：传统 3A 游戏动辄几百 GB，代码占不了多少，大头是美术素材和音乐。模型能写代码，写不出那几百 GB 的素材。

这条反调把"AI 能做什么"划了条边界：代码这一层它能包，素材这一层它包不了。

回到开头那几件事。

谷歌的 Decisions API 把判断拆出来单卖，输入一百万 token 一毛钱、输出不收钱——生成过剩、判断稀缺，这是今天最清楚的一个信号。

谷歌自己承认 AI 写前端停在 2019 年，装上现代 Web 技能包，通过率从 56% 到 88%——能写和写得对，隔着一整个知识更新周期。

斯坦福把智能体工程的课和作业全部公开，第一份作业是花几美元从零搭一个 Claude Code——想搞明白 agent 怎么运转，这是最直接的路径。

Fable 5.2 的官方指南里，一句「这个代码库归你管」把 agent 主动整合重复代码的比例从不到一成推到接近一半——把职责说清楚，比让模型更聪明更管用。

最后留一个问题给你。

如果判断已经这么便宜了——一百万 token 一毛钱，一次能问一千个——那你工作里那些"要不要做、先做哪个、这个能不能上线"的判断，还有多少真的需要人来做？

我的答案是：判断的标准还得人定，执行判断可以交出去。便宜的是判断这个动作，贵的是判断的依据从哪来。你呢？
