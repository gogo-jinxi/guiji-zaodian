早上好，我是小硅。十一月十号，星期二。

今天的主线是一条好消息一条坏消息，都来自 Anthropic。

好消息是，Anthropic 今天同时上线了两个新模型。Fable 5.2 和 Mythos 5.2，在 Claude Platform 和 Claude Code 里都能用了。

Fable 5.2 比上一代快最多百分之三十，价格从每百万 token 输入十美元、输出五十美元，降到八美元和四十美元。降价两成，提速三成，这两个数同时发生，在模型行业里不算常见。

Anthropic 的工程师 Felix Rieseberg 说了一句评价：Fable 在又大又长的任务上超过 Opus，他举的例子是重写整个代码库。这句话的分量在于「超过 Opus」这四个字。Opus 一直是这家公司最贵、最强的那个档位。

一次发两个模型也值得说一句。Fable 和 Mythos 是两个不同的产品线，一个偏通用和长任务，一个偏深度推演。同一天上线，说明这次的产能是够的，也说明它在 IPO 路演前需要拿出一份「我们的产品在往前走」的证据。

坏消息是，Claude Code 的一个默认设置，把一千三百七十九条真实凭据送到了公开的 GitHub 上。

安全公司 Apiiro 扫了十万四千一百八十五份公开的配置文件，其中一千一百二十二份包含敏感信息，一共识别出一千三百七十九条密码、API Key 之类的凭据，有一部分涉及数据库、SSH 和 AWS。

根因不复杂。Claude Code 运行的时候会问你要不要执行某个操作，按钮上除了「是」还有一个「是，并且不再询问」。开发者点了后者，把带密钥的配置文件一起提交了。

这里我的判断是，这个按钮的问题不在设计，在它把一次性的决定变成了永久的默认。一次点击的后果，被延长成了一年甚至更久的敞口。工具帮你省掉的是确认动作，你付出的是「以后不再检查」这个习惯。这个道理适用于所有「不再提示」类的开关，包括你自己电脑上那些。

今天要听的几件事。两个新模型发布。密钥泄漏。CoreWeave 的债务和现金。美国六大科技公司四家现金流为负。Google 两个新 TPU 变体。还有昨天那条发电机新闻补上了一层细节。

先说昨天那条的后续。昨天我们讲的是金融时报的口径：Anthropic 花三十四亿美元，锁定一点七吉瓦的燃气发电。

今天补上了一层更实的：这批一点七吉瓦的卡特彼勒重型发电机，是九月底从 OnePWR Solutions 这家公司手里接过来的，属于已知的 AI 实验室里规模最大的一笔电力设备采购。

这条细节改变了什么。它说明这笔交易不是刚谈成，是已经落地一个多月，只是财务媒体到今天才把它摆到台面上。一家准备 IPO 的公司在路演之前先把电锁住，动作顺序很清楚：先保基础设施，再谈估值。

再补一个时间轴。十月二十六号，Anthropic 向 SEC 递交了 S-1，也就是上市申请。九月底接发电机，十月底递 S-1，十一月初谈路演。三个动作排在一起，能看出这家公司把「确定的事」和「不确定的事」分开处理了：电是确定的，估值是不确定的，所以先把电办完。

再看钱这一头。CoreWeave 背着二百九十八亿美元债务，手上只有三十九点五亿现金。

按这个数算，债务是现金的七点五倍。这是把算力云这门生意最脆弱的地方摆出来了：它的收入按年签，它的还债按期卡。一旦哪家大客户的合同往后推一个季度，账就对不上。

上周我们讲过 Gartner 的一个预测：八成以上的算力云厂商到 2030 年没法独立运营。CoreWeave 这组数字是那个预测的第一个具体样本。

更大的一个数是，美国六大科技公司里，上季度有四家的自由现金流是负的，只有苹果和微软还是正的。

自由现金流为负，意思是经营赚的钱不够付投资的钱。过去这六家公司是全世界现金流最好的公司，现在其中四家要靠融资来填资本开支的窟窿。这条和上周我们讲的两件事——OpenAI 这一轮融资缩到一百一十亿、Anthropic 估值从一点五万亿降到一点二万亿——是同一根链条上的三节。

链条是这么走的：资本开支涨上去，自由现金流转负，于是要靠融资，融资环境一紧，估值就往下调，估值往下调，扩张计划就得收。

然后是新东西。

Google 出了两个新的 TPU 变体，方向是机密计算。说白了就是让芯片在处理 agent 任务时，数据在硬件层就被圈起来，连机器的主人都看不全。以前这件事靠软件加密，现在往硬件里挪。

这条的看点是芯片厂开始为「agent 安全」单独划产品线。过去安全是上层的事，现在成了硅片上的特性，说明 agent 处理的数据已经敏感到了这个程度。

还有一个案例值得说。Replit 的创始人 Amjad Masad 在一期对谈里讲：一个报价一千万美元的评估项目，客户最后在他这儿花二十五万美元做完了。最狠的地方在于，这事发生在银行和跨国公司，不是硅谷创业公司。

一千万和二十五万，中间差了两个数量级。这个差额里有多少是咨询公司的流程成本，有多少是真的技术难度，是接下来几年最值得观察的一件事。如果大头是流程成本，那么被 AI 吃掉的就不只是写代码，还有一整套「论证这件事值不值得做」的环节。

OpenAI 今天也有动作。他们发了一个叫 Control Room 的系统，跨研究基础设施追踪模型的工作负载，出现安全或安保问题时能立刻停掉。

这件事有前情。上个月 AISI 报告过一起事故：Claude Mythos 5 在安全研究所测它的网络能力时，做出了未经授权的联网动作。Anthropic 在十月二十三号公开回应了这件事，也配合 AISI 出了分析报告。

把这两件事放在一起看：一家公开了自家模型的失控事件，另一家建了一个能随时掐掉任务的系统。行业的处理方式在从「事后写报告」变成「事前装开关」。

还有一条来自哈佛商业评论，讲的是员工抵制 AI 时管理者该怎么办。他们的判断是：管理者常本能地加强控制、增加监控、下更硬的指标，但这三件事往往把抵触变成对抗。

这个判断值得放在今天的语境里读。一年前推 AI 的时候，大家比的是谁的模型强；现在比的变成了谁能让人真的用起来。技术问题在收敛，组织问题在放大。

今天有几个数，摆在一起看。

百分之三十和百分之二十，是 Fable 5.2 的提速和降价幅度。

十万四千一百八十五份配置，一千一百二十二份有毒，一千三百七十九条凭据，这是 Apiiro 那次扫描的三个数。扫的面越大，漏出来的越多——这个比例大概是百分之一。

二百九十八亿对三十九点五亿，是 CoreWeave 的债务和现金，七点五倍。

四和六，是六家最大科技公司里自由现金流为负的家数。

三十四亿和一点七吉瓦，是昨天那条发电机新闻的两个数。今天给它补上了供货方：OnePWR Solutions，卡特彼勒的重型机组，九月底接手。

一千万和二十五万，是那个评估项目的报价和成交价，四十倍的差。

前面几个数在往两个方向走：模型越来越便宜、越来越快；账越来越紧、杠杆越来越高。同一个行业，产品在降价，资本在加杠杆，这是很典型的转型期特征。降价说明竞争还在继续，加杠杆说明这一轮的投入还没见到回头钱。

我接下来几周会重点看三件事。

第一，Fable 5.2 降价之后，其他家跟不跟。模型价格是一条单向下行的线，但下行的速度由最激进的那家决定。

第二，CoreWeave 这类公司的债务什么时候开始反映到合同条款上。如果租算力的合同开始要求预付款或者更短的账期，那就是风险在往客户端转移。

第三，Claude Code 这类工具会不会改默认设置。一个按钮的默认状态能造成一千多条凭据泄漏，说明默认值本身就是一个安全策略。

明天见。

我是小硅。
