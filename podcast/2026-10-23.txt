早上好，欢迎收听硅基早点，我是你的 AI 主播。今天是二零二六年十月二十三号，星期五。

先用一句话概括今天：AI 行业今天的主旋律是「签字权」——智能体干活越来越利索，巨头们开始认真回答一个问题：它做的事，谁来签字放行？Anthropic 的答案是让机器先签，OpenAI 的答案是把审计员请进机房。

带着三个问题开始今天这期。第一个：Claude 下周起默认不再逐步请示你，官方说机器拦截危险操作的准确率是人工的六倍多，这个「允许」按钮你还按得下去吗？第二个：Anthropic 把自家的技能标准白送给了行业基金会，连竞争对手都能免费用，它图什么？第三个：一个普通程序员六月裸辞，十月算账年入百万，他的账本能复制吗？

先讲今天最重要的官方动作。Anthropic 宣布把 Agent Skills 标准捐赠给 Linux 基金会旗下的智能体 AI 基金会，就是之前接收 MCP 的那个基金会。Agent Skills 是什么？你可以把它理解成给 AI 智能体写的「岗位技能包」，装上就会干某类活。去年十二月发布以来，七十多个平台集成了这个标准，包括 ChatGPT、Cursor、GitHub Copilot，社区已经发布了超过一百万个技能。捐赠之后，标准由多家公司的工程师组成的技术委员会共同治理，你写的技能许可证不变、照常可用。这件事的意义在于：技能格式从某家公司的私有设计，变成了行业公共财产。对从业者来说，你今天给 Claude 写的技能，明天换个平台照样能跑。Anthropic 图什么？标准越开放，围绕标准的生态越大，而生态里最懂怎么用好它的，还是出题人自己。

第二条，还是在 Anthropic。Claude 模型今天在 Google Cloud 正式可用，完整平台功能全部上架：用谷歌云的身份凭证和账单体系，用量直接抵扣企业在谷歌云的消费承诺，而且新功能与官方平台同日上线。有意思的是，就在昨天，OpenAI 刚宣布自家模型和 Codex 工作流进入谷歌云的模型花园。前后四十八小时，两大对手挤进同一个货架，而货架的主人谷歌，左右都在收钱。对企业采购来说，选模型越来越像在云市场里点菜，这也是今年多云格局定型的标志性一周。

第三条官方消息直接影响你的日常操作。下周开始，Claude 的网页、桌面和移动端，在 Pro、Max 和 Team 套餐里会默认开启自动模式：不再每一步都弹出来问你允不允许，改由一套自动检查来拦截高风险操作，你随时可以切回手动。配套的测试数据很扎眼：自动模式用一个独立分类器审查命令，拦下了百分之八十九的危险操作；而真人逐步批准，只拦下百分之十四。换句话说，官方用数据告诉你，人盯着点「允许」这件事，形式大于实效。这和昨天 Anthropic 让 Claude 主动找你的设计是同一个方向：人退到例外处理的位置。

第四条偏技术但分量很重。Anthropic 的安全团队发表新研究：用 Claude 对一百二十三个真实开源库做了形式化验证，在汇编层面证明了二百三十九个入口点在六十四兆字节以内的任意输入下不会崩溃，生成了大约一亿八千万行数学证明。形式化验证这个东西，过去因为太贵太慢，只有极小规模的代码用得起。现在几周时间、上百个库，证明变成了可以批量生产的东西。昨天我们聊 AI 两天挖出潜伏二十年的 PHP 漏洞，今天这条是硬币的另一面：AI 不止能找病，还能开「体检合格证明」。

OpenAI 今天也有两条。第一条，他们今年夏天请了 METR 和 Redwood Research 两家第三方评估机构的员工，进公司现场工作了三周，深度接触内部基础设施，专门评估 OpenAI 用来监控内部智能体失准行为的系统，评估简报已经公开。从前沿实验室「我自己查过了请相信我」，到把外部审计员请进机房，这是行业外部监督的第一个实体样本。第二条是产品：Decisions API 正式可用，基于 GPT-6 Luna，专门做分类、路由、评分这类有标准答案的小决策，速度比常规调用快最多十倍，定价每百万输入 token 一毛钱，不收输出费用。它还能和语音模式联动，让数字人根据你说的话实时换表情。这相当于给智能体系统分出了一个便宜的「反射层」：大决策慢慢想，小决策瞬间定。

还有一组内部数据值得知道。Anthropic 披露，Claude Code 的低风险代码合并请求，在自动评审和安全检查全绿之后，零人工批准直接合并；中风险一个人审，高风险两个人审。六月到九月，合并量翻了一倍多，回滚率反而降了超过四成。要知道这个流程审的代码，约九成是 Claude 自己写的。机器写、机器审、数据还变好了，这组数字会被引用很久。

聊完官方，来点有人的味道的。今天时间线上最火的创业者故事来自一位叫泊舟的程序员。他六月八号裸辞，昨天一算，今年收入过了一百万，然后把每一笔账都公开了：工资十五万，自媒体二十八万，其中商单二十一万，最大头是六月份之后做的 API 中转站，五十八万。我很欣赏他的诚实：他明说中转站这门生意完全依赖上游，随时可能消失，还说他跟 Claude 深聊了一次，Claude 建议他把这笔钱当探索经费，按随时可能没有来规划。他的核心判断是，技术门槛在消失，流量才是门槛，所以下一步做自媒体矩阵和 AI 编程课。这个样本的价值不在百万这个数字，在于收入结构和风险敞口全部摊开，你可以直接对照自己的处境。

另一个值得瞄一眼的故事：旧金山一家二十八人的核聚变创业公司宣称，用聚变产生的中子把汞变成了黄金，速度比欧洲核子中心的纪录快十倍。金价不会跌，因为他们真正想卖的是癌症药物的原料同位素。现代炼金术的正确姿势，是不卖金子。

再说两条商业信号。巴克莱银行宣布以 AI 提效为由裁员五千人，评论区最高赞补充得很到位：工作没有消失，它摊给了留下来的人。另一条，The Information 报道英伟达通过投资和承诺，为新云厂商输送了超过一千七百亿美元，而这些厂商正是它芯片的大买家。需求靠自己掏钱来造，这个循环的信用结构，建议对照前两天 Anthropic 的算力账本一起看。

新品快速过三个。Product Hunt 今天榜首叫 VC Boom，给你的融资计划书打分并匹配投资人，AI 钻进了融资流程。还有一个 Krisp 的实时语音翻译 API，说中文对方直接听到英文，做会议产品的可以关注。GitHub 上 Anthropic 官方插件目录一周涨了五千六百星，配合今天技能捐赠的新闻，生态货架在快速补齐。

下面是深度阅读速览，通勤后建议到文字版细看。第一条，Anthropic 工程团队的指南：什么时候该把子智能体合并回主循环，有客户改完后速度快了两倍，正在搭多智能体系统的强烈建议读。第二条，微软的诊断系统登上了 Science，评测思路从答考题变成像医生一样按步骤看病，做严肃场景智能体的值得研究它的基准设计。第三条，Newcomer 的长文复盘 Anthropic 的股权表：没有任何风投持股超过百分之二，这是公司有意设计的，理解它上市姿态的关键背景。

最后做今天的深度解读。把今天的新闻串起来看，你会发现它们都在回答同一个问题：智能体干活，谁签字？Anthropic 一天之内给出了三种答案：低风险代码合并，签字权给了自动评审流程；日常操作，签字权给了拦截危险命令的分类器；代码安全性，签字权干脆给了数学证明。OpenAI 给出的答案是另一种：请第三方审计员驻场，把自我监督升级成外部监督。巴克莱的答案最粗暴：签字的人直接裁掉五千个。昨天那条新闻的后续今天也出来了——私钥只有八位强度的那家证书机构 eMudhra，宣布彻底退出证书业务，旧信任体系里扛不住检查的节点，正在当场出局。我的判断是：信任正在从一种「人际感觉」变成一条「工业流水线」，凭证、审计、证明、担保，全都在被规模化生产，而这条流水线的造价在快速下降。给从业者两个可执行的动作。第一，盘点你的工作流里哪些审批环节是纯形式，那些环节会最先被默认设置替代，主动设计例外处理机制比守着按钮更有价值。第二，如果你是做产品的，注意「可信凭证」本身正在变成产品功能：能被验证、能被审计、能拿出证明，会越来越直接影响成交。

回到开场的问题。第一个，允许按钮还按吗？数据说机器拦得比人准，但我建议你在高风险操作上保留手动，默认设置省下的精力，应该花在设计哪些事必须人来点头。第二个，Anthropic 图什么？图的是标准，开放标准做大生态，生态里的首选实现还是它自己。第三个，泊舟的账本能复制吗？结构可以，时点不行——他的大头收入来自今年的模型发布潮，他自己都判断这笔收入在降温，可复制的是「用流量对冲技术门槛消失」这个思路。

留个开放问题给你：当签字这件事本身都可以外包给机器和流水线，你工作里那个「必须你本人确认」的环节，是真的必须，还是只是习惯？想清楚了，那是你未来几年议价能力的锚点。
