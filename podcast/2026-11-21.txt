早上好，我是小硅。今天是十一月二十一号，周六。

今天报四件事。
Anthropic 上市第二天跌近一成，全球 AI 股跟着下挫。
一位数学家说 Claude 帮他证出了广义黎曼假设。
Signal 开始阻止 AI 读取聊天截图。
谷歌开始给 agent 的每次调用装审查。

先说市场这一头。

今天收在八十八块一毛七，比前一天的收盘跌了百分之九。
离发行价只剩五个美元出头。
十二个独立信源同时报了这件事，讨论量排当天第一。
上一期我说过，这家公司给全行业立了必须每季交表的规矩。
今天要补的后半句是，规矩立起来，打分也就开始了。

跌的不只是它一家。
周五纳斯达克指数收跌百分之二。
存储芯片两家跌得最狠，闪迪跌百分之十四，美光跌百分之十。
存储是这一轮 AI 服务器的关键一环，跌得最狠说明抛售打到了产业链条上。
亚洲市场更难看，台湾加权指数一周跌百分之六点七。
台股权重集中在半导体，指数跌这么多等于把整条供应链重估了一遍。
日经跌百分之五，韩国综合指数跌百分之五点五。
这是二〇二〇年以来最差的一周。
软银单日跌百分之十四点五，它手里那批 AI 资产的估值跟着缩水。

从盘面看，下跌有两层原因。
一层是打新的人卖了，认购阶段抢到的份额，上市第二天兑现最划算。
另一层是指数被动资金进场后，权重一变，波动就被放大。
两件事叠在一起，首日那点涨幅很难守住。

这轮下跌能传遍亚洲，跟权重结构有关。
几个主要市场里，AI 和半导体占指数的比重都比五年前高得多。
一个板块跌，指数就跟着跌，普通人买的基金也跟着缩水。

同一天晚上还出了一条消息。
有报道称，美国证券交易委员会在调查英伟达的会计处理。
消息来自引述知情人士的报道，在技术社区拿到一百八十分。
这条敏感的地方在于口径，供应商投给客户的钱记成什么，记收入还是记权益，差别很大。
调查覆盖哪些年度、查的是哪一类交易，目前都没有公开。
这件事要等公司或监管方回应才算数，现在只能算待核。

跌完之后它还在发行价上方，说明当初定价留了余量。
没上市的那批公司，将来定价都要参考这个二级市场价格。

两条放在一起看，我这样判断。
上市首日涨的是稀缺性，全市场只有这一只票能买。
第二天跌的是流动性，认购的钱撤了，故事就得自己站住。
估值参照和财报可信，这两根柱子在同一晚被同一批人质疑。
一家刚把报表摊开的公司被查账，另一家刚上市的公司被卖出，问的是同一个问题。

接下来这件事，比股价难消化得多。

一位叫 Levent Alpöge 的数学家，昨晚在个人网站发了一个声明。
他说自己和 Claude 合作，证出了黎曼猜想。
更准确地说，他放出的文件标题写的是广义黎曼假设，那是黎曼猜想更强的一个推广版。
这个问题一八五九年由黎曼提出，问的是素数在数轴上怎么分布。
它到今天还是悬案，也是千禧年大奖难题之一，悬赏一百万美元。
前后合作大约六周，他说 Claude 提出了关键的那一步。

他没有写论文。
放出来的是十四个压缩包，一共十七万五千多个 Lean 文件，一千七百三十七万行代码。
Lean 是一个开源的定理证明器，由微软研究院发起，能把证明写成机器逐行检查的代码。
一般中型软件项目也就几十万行，这个体量是它的几十倍。
这些文件每一个都要能被证明器接受，错一处就编译不过。
好处是错的地方能被机器指出来，坏处是没人知道该从哪一行开始看。
按引述的说法，完整论证约二十五万页。
目前没有人类能把这个证明从头到尾读一遍。
代码包已经在网上公开，任何人下载都能自己跑一遍检查。
论文要等几个月评审，代码复核当场就能开始，这是它比论文快的地方。

技术社区的反应很直接，这一条拿到两千二百五十七分，是当天首页最高分。
数学家陶哲轩同一天发了博客，讨论另一道流体方程的奇点问题，以及它跟广义黎曼假设的关系。
一个宣布证完，一个继续拆问题，两种节奏同时存在。

我先说清楚不确定的地方。
机器能检验，不等于数学界接受。
数学界的惯例是先投期刊、过同行评议，这次跳过这一步，等于把验证的成本转给了读者。
二十五万页摆在面前，谁来读，谁来复查，这本身成了新瓶颈。
六周这个时长也要打个问号，一个悬了一百六十多年的问题，六周出结果，至少要等独立复核。
还有一层，机器验的是代码有没有错，验不了前提选得对不对。
如果最终被接受，克雷数学研究所要付一百万美元奖金，这个悬赏从二〇〇〇年挂到今天。

这次真正的变化在分工。
以前模型是查文献、算符号、验算式的助手。
这次关键步骤由模型提出，人做的是形式化和搬运。
如果最后被数学界接受，这件事的分量会和模型在数学上的其他成果不在一个层级。

昨天我刚讲过 Claude 解了黑洞物理的两个开放问题。
连着两天，模型在基础科学上出结果。
这类案例一年前还叫作辅助，现在开始写进结论。

第三块讲权限。

昨天讲谷歌让 Mac 版 Gemini 动手操作电脑。
今天出现了方向相反的动作。

通讯软件 Signal 更新了限制，在苹果新系统和安卓上禁止截图。
目的写得很明确，阻止系统级的人工智能读取聊天内容。
这条在技术社区拿到四百七十三分。
一家做加密通讯的公司，把防线从加密传输推到了禁止截屏。
道理不难，截图绕过了加密，屏幕上的内容本来就是明文。

这个动作的意义在位置上，它防的是本机运行的助手，跟网络攻击无关。
当一个助手能看见整块屏幕，加密传输保护的就只是路上那一段。
要守住内容，就得让屏幕本身别被复制。

同一天，谷歌在平台上发了一套治理策略。
名字叫语义治理，做法是在 agent 每次调用工具之前先审一遍。
审两件事，这次调用是否符合用户最初的意图，是否符合用自然语言写下的策略。
审查由一个网关加一个模型裁判完成，不合格的调用在执行前就被拦下。
工具调用是 agent 真正动手的那一步，把审查放在执行前，等于把责任往前挪了一格。
两个检查点分开也有用意，用户想要的是一层，公司允许的是另一层。
这套策略现在是预览版，还没有强制。
但位置很关键，它把合规检查放进了调用链，样板立起来，别家大概率会跟。

另外两条可以放在一起看。
Perplexity 的电脑版进了浏览器，从侧边栏接管任务，你能看见它在多个标签页和工具之间跑。
Meta 的 Muse 给智能体发了独立邮箱，可以代表用户收发邮件，用户还能认领一个句柄。
邮箱这条比浏览器那条更靠前，发出去的信是以用户身份写的。
这里有个新问题，收件人没法确认回信的是人还是 agent。
企业邮箱收到代写的信，现在没有统一标识可用。

这两组动作方向相反，落在同一件事上：授权。
agent 的能力扩张到哪里，授权就得跟到哪里。
以前授权是一次性的，点一次同意就行。
现在授权成了产品的一部分，要按每次调用和用户原本的意图来判断。
这条线往前走，下一版产品比的可能是谁的刹车更细。

再给几条快的。

Thinking Machines 开源了一个更小的模型，叫 Inkling 2 Mini。
二百六十亿参数，已经在 Agent Arena 上架，可以本地跑。
上周它的上一个尺寸在两个榜单上超过了 DeepSeek 的一款快速模型。
这次挑战的是能装进个人设备的体积。
开源阵营在同一架构上下探，端侧这条线在加速。

ChatGPT 的协作空间开始向 Plus 用户开放。
此前只有专业版、商业版和企业版能用。
每月二十美元的档位现在也能建共享页面、幻灯片和交互图表，还能拉人一起改。
协作从企业采购变成个人订阅，价格门槛一降，用的人会明显变多。

一家叫 NaceAI 的公司发了个路由模型，名字叫 Drex Router。
你给它一段提示词和一串候选模型，它五十七到八十七毫秒内选一个。
在一千四百道常识题上准确率百分之八十七点六，每千次调用一毛钱。
对比的另一套路由方案准确率百分之八十六点四，价格是一块零九。
它还给出每个候选模型的概率和一句理由，不只给一个名字。
省下来的钱不多，但它把选模型这件事从人拍脑袋变成一次计费很低的调用。

Runway 公开了把软件交付交给 agent 的做法和验收数字。
十月有百分之三十八的合并请求由 agent 驱动，六月这个比例是千分之一。
第一次批准的等待中位数从两小时以上降到约五分钟。
agent 单独批准的请求回滚率约千分之一，人工批准是两百分之一。
这四个数字连起来，是自动化第一次在质量指标上不输人。
难点不在写代码，在敢让 agent 自己批。
审批权交出去之后，出了问题算谁的，这条还没答案。

腾讯混元正式开源了办公用的小激活模型，同时发了一份系统卡。
上周预告过权重会放出来，这次是正式版加披露文档。
开源配上系统卡，等于把能力和风险一起交出去。
对想自己部署的团队来说，这比单给一份权重更有用。
国内开源模型最近都在配系统卡，这已经成了新惯例。

HeyGen 发了一个只出概率不出字的视频模型，叫 Decision 1。
你给它文本、图片、视频或音频，它用概率回答最多四百个问题。
代码可以直接根据概率行动。
视频 AI 从生成内容转向判断内容，这一步先出现在质检类任务上。

OpenAI 还公布了一条科研合作。
他们和两家研究机构一起，用一个专门训练的模型找神经退行性疾病的新线索。
模型在这类工作里的角色，是从海量实验数据里挑出可以继续跟进的方向。
药物研发的早期筛选一直是最费人的环节，这一步提速，后面整条线都会跟着变。

一位叫 Lauren Tan 的工程师分享了一个清理代码注释的小技能。
做法是把注释分成四类，同义重复、找借口、过时、决策记录。
前两类删掉，过时的修，决策记录归档进架构文档。
她建议把这件事做成 lint 规则，不要每次靠人提醒。
这跟她上个月提的做法一致，把纠正沉淀成规则，别堆在提示词里。

还有一条跟昨天的方向接得上。
Latent Space 写了一篇长文，讲形式验证怎么对付模型写的低质量代码。
几家团队的做法是把定理证明器接进流水线，让机器先验一遍再提交。
这条路走通了，代码审查的瓶颈会从人转移到证明器。
和今天那条数学新闻放在一起，是同一个工具往两个方向用。

行业侧面还有一条。
GitHub 上本周涨得最快的是一个让 coding agent 跟上最新网页规范的仓库，一周近七千星。
排第二的是一份中文代码审查工具，一周四千五百星。
榜单前列基本都是在给 agent 补规则、补护栏的工具，这个方向的需求已经很明确。
前十名里有一半，做的都是同一件事。

今天就到这儿。
